# にゃんこ大脱出 🐱

おじいちゃんの家から、おそうじロボットに捕まらずキャットタワーへ逃げるターン制パズル。**全20ステージ**。

**`index.html` の1枚で完結**（外部ライブラリ・画像素材ゼロ）。同じフォルダにあるのは書体だけ。

```bash
./run.sh                              # http://127.0.0.1:8543 で開く
../app-start.sh neko-escape --shot    # 起動して画面も撮る
open "http://127.0.0.1:8543/index.html?stage=13"   # ★そのステージから始める（確認用）
```

> **`file://` で開かない。** 書体（`assets/fonts/*.woff2`）の読み込みがブラウザに止められ、
> 「手元では平気なのに実際は豆腐」を取り違える。確認は必ず HTTP で。

## 見た目のつくり（2026-08-28 に作り替えた）

盤面は `<canvas>` に手で描いている。**外部の画像素材は1枚も使っていない**（絵文字も盤面からは全廃した。
端末ごとに絵柄が変わり、キャラクターの表情も付けられないため）。

座標は **900×600 固定**で、CSS 側で幅に合わせて伸ばす。マスの座標（ステージデータの 0〜100）は
外周に余白（`PADX=44` / `PADY=52`）を残して写す。**余白を削ると端のマスとキャットタワーが切れる。**

| 層 | 中身 | 関数 |
|---|---|---|
| 床 | フローリング・ラグ・幅木・窓から差す光・四隅の陰 | `buildFloor()`（**1枚に焼いて使い回す**） |
| 道 | マスとマスをつなぐ廊下（帯＋破線） | `drawBoard()` 内 |
| マス | 座布団。緑の脈動＝動ける／**赤い破線＝次にロボットが来られる** | 同上 |
| 置物 | ソファ・毛糸・さかな・落とし穴・キャットタワー | `drawSofa` / `drawYarn` / `drawFish` / `drawTrap` / `drawTower` |
| キャラ | ねこ（まばたき・しっぽ・ぶち）／ロボット（LEDの目・アンテナ・ブラシ） | `drawCat` / `drawRobot` |

**HUD・凡例・結果画面の小さいアイコンも、盤面と同じ描画関数で描いている**（`ART` 表 → `paintIcon`）。
別々に作ると絵柄が食い違うため。絵ごとに「原点から上下にどれだけ伸びるか」を持たせて箱に収める。

### はまった所（同じことを繰り返さないために）

- **`ctx.ellipse()` は半径が負だと `IndexSizeError` を投げ、描画ループごと死ぬ。**
  猫が跳ねている間の影を `17 - hop*4` と引き算で書いていて、`hop` が大きいと負になった。
  **例外で `requestAnimationFrame` の輪が切れると、進行タイマーも止まって盤面が固まる**
  （操作を受け付けなくなり、一見「ロボットが動かないバグ」に見える）。
  → 影は掛け算で縮める＋**次のフレームを関数の先頭で予約する**（描画が転んでも輪は回る）。
- **進行に `setTimeout` を使わない。** 描画ループの中で秒を数える（`after()` / `timers`）。
  ステージをやり直すときに全部まとめて捨てられるし、裏に回っても絵と進行がずれない。
- タブのアイコンは **data URI で埋め込む**。外部ファイルにすると `favicon.ico` の 404 が
  Console に残り、本物のエラーが埋もれる。

### 書体（Zen Maru Gothic・SIL OFL）

`assets/fonts/ZenMaruGothic-{500,900}.woff2` を同梱（商用可・埋め込み可・**再配布可**）。
丸ごとの日本語フォントは数MBあるので、**画面に出る文字だけ**に絞ってある（各45KB前後）。

```bash
python3 tools/fetch-font.py          # 取り直す
python3 tools/fetch-font.py --check  # いま何字使っているかだけ見る
```

> **`index.html` の文言を変えたら必ず流し直すこと。** 忘れると増やした字が □ になる。
> Google Fonts の css2 API に `text=` を渡すサーバ側サブセットなので `fonttools` は要らない。
> スクリプトは **HTMLのテキストとJSの文字列リテラルだけ**を拾う（ソース全体をなめると
> 日本語コメントの漢字まで拾ってフォントが倍近くに膨らむ）。

### 音

**音のファイルは同梱していない。** 効果音9種もBGMも `index.html` の中で WebAudio により合成している。

録音した素材に差し替えたいときは、`assets/audio/` に `step.mp3` `fish.mp3` …（名前は `SFX_FILES` のとおり）を
置いて `USE_FILES = true` にするだけ。無いファイルはそのキーだけ合成音のまま鳴る（落ちない）。

> 持ち込んでよいのは**商用可 かつ 再配布可**の素材だけ（このリポジトリは public）。
> 効果音ラボ（商用可・表記不要）か CC0 が安全。

BGM はハ長調のペンタトニック（ド・レ・ミ・ソ・ラ）だけを使う。どの順に鳴らしても濁らないので、
短いループでも耳障りになりにくい。iOS は画面を触るまで音を出せないので、最初の操作で `AudioContext` を作る。

## 難易度（2026-08-28 に総当たりで測った）

ロボットは決定論（毎ターン BFS で最短1マス）なので、**全ステージを解いて難しさを数で言える**。

```bash
node tools/analyze-stages.js     # 全20面を解いて表を出す。★ステージを触ったら必ず流す
```

| | 実測 |
|---|---|
| 解けない面 | **0**（20面すべてクリア可能） |
| 最短手数 | 3〜9手（平均 **5.8手**）。大人なら全20面を10分ほどで完走できる |
| 状態数 | 4〜228（浅い。1面あたりの考えどころは小さい） |
| でたらめに押したときの勝率 | 平均 **2.9%**（3面は0.5%）＝**適当に押すと勝てない＝読みは要る** |
| いちばん厳しい面 | **9「挟み撃ち」（勝ち筋率43%）** と **10「最後の牙城」（47%）** |
| 最終面 | 20 は勝ち筋率 **89%**＝ほぼどう動いても勝てる。**難易度カーブは効いていない** |

**分かったこと**: 後半は「敵とマスが増えただけ」で一手の重みは軽くなっている。
ギミックは13面で出そろい、以降に新要素が無い。手を入れるなら
**①★評価（最短手数）②後半の面を追加 ③1手もどす ④14面以降の新ギミック** の順に効く。
