# ネオンエスケープ

追撃機に捕まらず、ワープゲートへ離脱するターン制パズル。**全40ステージ**。
（2026-08-29 に「にゃんこ大脱出」から改題。フォルダ名 `neko-escape` はそのまま）

**★データ上の名前は昔のまま。** ステージ表と `tools/engine.js` が
`cat / robots / sofa / yarn / fish / trap / catOnly` の名前で書かれているので、
**見た目と呼び名だけを読み替えている**。ここを直すと解析器とズレる。

| データ名 | いまの呼び名 |
|---|---|
| `cat` | 自機 |
| `robots` | 追撃機 |
| `goal`（tower） | ワープゲート |
| `sofa` | ブロック壁（追撃機が入れない） |
| `yarn` | EMP機雷（踏んだ追撃機が1ターン停止） |
| `fish` | ブースター（もう1マス動ける） |
| `trap` | 特異点（追撃機だけ消える） |
| `catOnly` | スリット（自機だけ通れる） |
| `sw` / `doors` | 起動パネル / エナジーゲート |

**`www/index.html` の1枚で完結**（外部ライブラリ・画像素材ゼロ）。同じ場所にあるのは書体と、
Appleの必須ページ（`support.html` / `privacy.html`）だけ。iOSアプリ版も同じ1枚を包んでいる。

```bash
./run.sh                              # http://127.0.0.1:8543 で開く
../app-start.sh neko-escape --shot    # 起動して画面も撮る
open "http://127.0.0.1:8543/index.html?stage=13"   # ★そのステージから始める（確認用）
```

> **`file://` で開かない。** 書体（`www/assets/fonts/*.woff2`）の読み込みがブラウザに止められ、
> 「手元では平気なのに実際は豆腐」を取り違える。確認は必ず HTTP で。

## ルール

全40面。**1〜20面のルールとステージデータは 2026-07 の版から変えていない**。
21〜30面（2026-08-28 追加）に新ギミック2つ、**31〜40面（2026-08-29 追加）は高難度パック**。

**盤は縦（600×900）**。ステージ座標は 0〜100 の「横長」で書いてあり、
`NX/NY` が **90°回して**写している（もとの左→右の脱出が、画面では下→上）。
面ごとに、実際に使っている範囲へ引き伸ばす（`buildFit()`）。

**手番の進み方**: 自機が1マス動く → 追撃機が**全台同時に**1マス動く（1手 約0.5秒）。
さらに **2.6秒 手が止まると、追撃機だけが1ターン動く**（警戒ゲージ）。
★ゲージが動くのは「その面の最初の1手を打ったあと」から。盤面を読む時間は取れるようにしてある。
★手数は増えないので、**★の最短手数の基準は変わらない**。

| | |
|---|---|
| 自機 | となりのノードへ1つずつ。**ブロック壁のノードにも入れる** |
| 追撃機 | 毎ターン、最短経路で1マス近づく（幅優先探索）。**ブロック壁と他の追撃機のノードには入れない** |
| EMP機雷 | 追撃機が踏むと1ターン止まる（踏んだ機雷は消える） |
| ブースター | 自機が乗るともう1マス動ける（ターンが継続する） |
| 特異点 | **追撃機だけ**吸い込まれて退場。特異点は残る。自機は平気 |
| 🏰 タワー | 着けばクリア |
| **スリット**（21面〜） | **自機だけ通れる道**。追撃機は迂回になる（ブロック壁の「道」版） |
| **起動パネルとエナジーゲート**（21面〜） | 自機がパネルを踏むと、閉じていたゲートが開いて道がつながる（一度きり・戻らない） |

道は2種類ある。**自機用（`adj`）と追撃機用（`radj`）を分けて持つ**のが実装の要点で、
追撃機の経路探索は必ず `radj` を使う（`adj` を使うとスリットを通ってくる）。

## ★評価

★★★＝最短手数ぴったりでクリア／★★＝最短+2手以内／★＝クリア。
**各面の最短手数（`opt`）は人が数えた値ではなく、`tools/analyze-stages.js` が総当たりで
出した値を貼ってある。** ステージや道を触ったら必ず貼り直すこと（★3が取れなくなる）。

```bash
node tools/analyze-stages.js --opt     # 貼り直す値と、ズレている面を出す
```

## 見た目のつくり（2026-08-28 に作り替えた）

盤面は `<canvas>` に手で描いている。**外部の画像素材は1枚も使っていない**（絵文字も盤面からは全廃した。
端末ごとに絵柄が変わり、キャラクターの表情も付けられないため）。

座標は **900×600 固定**で、CSS 側で幅に合わせて伸ばす。マスの座標（ステージデータの 0〜100）は
外周に余白（`PADX=46` / **上 `PADT=104`** / 下 `PADB=56`）を残して写す。
**上だけ広いのは、ワープゲートがノードより約80px 上へ伸びるから**（同じにすると盤の上ぶちで切れる）。

| 層 | 中身 | 関数 |
|---|---|---|
| 床 | フローリング・ラグ・幅木・窓から差す光・四隅の陰 | `buildFloor()`（**1枚に焼いて使い回す**） |
| 道 | マスとマスをつなぐ廊下（帯＋破線） | `drawBoard()` 内 |
| ノード | 暗いパネル。緑の脈動＝動ける／**マゼンタの破線＝次に追撃機が来られる** | 同上 |
| 置物 | ブロック壁・EMP機雷・ブースター・特異点・ワープゲート | `drawSofa` / `drawYarn` / `drawFish` / `drawTrap` / `drawTower` |
| キャラ | 自機（ブロック製・上向き・推進の炎）／追撃機（2色市松ブロック・センサーの目） | `drawCat` / `drawRobot`（**名前はデータに合わせて据え置き**） |

**HUD・凡例・結果画面の小さいアイコンも、盤面と同じ描画関数で描いている**（`ART` 表 → `paintIcon`）。
別々に作ると絵柄が食い違うため。絵ごとに「原点から上下にどれだけ伸びるか」を持たせて箱に収める。

### はまった所（同じことを繰り返さないために）

- **`ctx.ellipse()` は半径が負だと `IndexSizeError` を投げ、描画ループごと死ぬ。**
  猫が跳ねている間の影を `17 - hop*4` と引き算で書いていて、`hop` が大きいと負になった。
  **例外で `requestAnimationFrame` の輪が切れると、進行タイマーも止まって盤面が固まる**
  （操作を受け付けなくなり、一見「追撃機が動かないバグ」に見える）。
  → 影は掛け算で縮める＋**次のフレームを関数の先頭で予約する**（描画が転んでも輪は回る）。
- **進行に `setTimeout` を使わない。** 描画ループの中で秒を数える（`after()` / `timers`）。
  ステージをやり直すときに全部まとめて捨てられるし、裏に回っても絵と進行がずれない。
- タブのアイコンは **data URI で埋め込む**。外部ファイルにすると `favicon.ico` の 404 が
  Console に残り、本物のエラーが埋もれる。

### 書体（Zen Maru Gothic・SIL OFL）

`www/assets/fonts/ZenMaruGothic-{500,900}.woff2` を同梱（商用可・埋め込み可・**再配布可**）。
丸ごとの日本語フォントは数MBあるので、**画面に出る文字だけ**に絞ってある（各45KB前後）。

```bash
python3 tools/fetch-font.py          # 取り直す
python3 tools/fetch-font.py --check  # いま何字使っているかだけ見る
```

> **`www/index.html` の文言を変えたら必ず流し直すこと。** 忘れると増やした字が □ になる。
> Google Fonts の css2 API に `text=` を渡すサーバ側サブセットなので `fonttools` は要らない。
> スクリプトは **HTMLのテキストとJSの文字列リテラルだけ**を拾う（ソース全体をなめると
> 日本語コメントの漢字まで拾ってフォントが倍近くに膨らむ）。

### 音

**音のファイルは同梱していない。** 効果音10種もBGMも `www/index.html` の中で WebAudio により合成している。

録音した素材に差し替えたいときは、`www/assets/audio/` に `step.mp3` `fish.mp3` …（名前は `SFX_FILES` のとおり）を
置いて `USE_FILES = true` にするだけ。無いファイルはそのキーだけ合成音のまま鳴る（落ちない）。

> 持ち込んでよいのは**商用可 かつ 再配布可**の素材だけ（このリポジトリは public）。
> 効果音ラボ（商用可・表記不要）か CC0 が安全。

BGM はハ長調のペンタトニック（ド・レ・ミ・ソ・ラ）だけを使う。どの順に鳴らしても濁らないので、
短いループでも耳障りになりにくい。iOS は画面を触るまで音を出せないので、最初の操作で `AudioContext` を作る。

## 難易度（総当たりで測る）

追撃機は決定論（毎ターン BFS で最短1マス）なので、**全ステージを解いて難しさを数で言える**。
**感覚で「難しくなった」と言わない。** ステージを足したら必ず流すこと。

```bash
node tools/analyze-stages.js     # 全30面を解いて表を出す
```

| | 1〜20面 | 21〜30面（2026-08-28 追加） |
|---|---|---|
| 最短手数（平均） | 5.8手 | **8.5手** |
| 勝ち筋率（平均・低いほど一手が重い） | 64.5% | **55.2%** |
| 解けない面 | 0 | 0 |

**2026-08-28 に測って分かったこと（これが追加ステージの動機）**: 1〜20面は最短3〜9手・
状態数は最大228で**浅く**、大人なら10分で完走できる。でたらめに押したときの勝率は平均2.9%
なので「読み」は要るが、**いちばん厳しいのは 9「挟み撃ち」（勝ち筋率43%）と 10「最後の牙城」（47%）で、
最終面20は89%＝ほぼどう動いても勝てる**＝難易度カーブが効いていなかった。
ギミックも13面で出そろい、以降に新要素が無かった。
→ **★評価・新ギミック2種・21〜30面**を足して、後半のほうが長く重くなるようにした。

### 道具（`tools/`）

| ファイル | 何をするか |
|---|---|
| `engine.js` | ルールの node 側の写し。下の3本が共有する |
| `analyze-stages.js` | 全面を総当たりで解いて難易度表／`--opt` で最短手数を出す |
| `gen-stages.js` | ステージを自動生成し、採点して条件に合うものだけ残す |
| `crosscheck.js` | **解析器と本体のルールがズレていないか突き合わせる**（下記） |

> **★ルールが2か所にある**（`index.html` と `tools/engine.js`）。ズレると
> **「解析器では解けるのに実機では解けない面」を配る**ことになる。ギミックを足したら必ず:
>
> ```bash
> node tools/crosscheck.js > /tmp/payload.js   # 出力をブラウザの Console に貼る
> ```
>
> 全30面を同じ手順で並走させて状態を1手ごとに比べる。2026-08-28 の実測で **236手・食い違い0件**。
> わざと期待値を1文字ずらすと検出できることも確認済み（＝空振りしない試験になっている）。
>
> 本体側は、追撃機の1ターンを **`planRobotTurn()` で先に全部計算 → 演出で再生**する形にしてある。
> 再生では**移動だけをまとめて同時に動かす**（1台ずつ待つと1手1.5秒かかっていた）。
> 計算と演出が分かれているから、演出抜きで同じ計算を呼べる。

## iOSアプリ版（2026-08-28・提出直前）

**Capacitor 8（SPM）で同じ `www/` を包んでいる**（`com.daikyo.nekoescape`・1.0/build 1）。
手順とハマり所は **`RELEASE.md`** にある。要点だけ:

- **本体は `www/`**。`deploy.yml` の取り出し元も `neko-escape:www`。
  **本体を動かすときは同じ push で deploy.yml も直す**（片方だけ push すると gh-pages が
  ステップごと落ち、**他のアプリの公開まで止まる**）
- `ios/` は git に入れていない。他PCでは `npm install` → `npx cap add ios` から作り直す。
  そのとき **`DEVELOPMENT_TEAM` は自動では書かれない**ので入れ直すこと（`RELEASE.md`）
- **`viewport-fit=cover` が要る**。無いと `env(safe-area-inset-*)` が 0 のままで、
  ヘッダーが Dynamic Island の下に潜る
- 広告・課金・通信・第三者SDK はゼロ（ipa を展開して実測済み）
