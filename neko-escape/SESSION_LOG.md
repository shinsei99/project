### 発生したエラーと解決策

- **敵4台の高難度面が1本も作れない** → 原因: 4台だと初手で詰む。**398面作って解けたのは3面**だけ。
  → 台数を増やすのをやめ、「道のりの長さ（10〜12列）」と「逃げ道の少なさ（勝ち筋率50%前後）」で
  難しくした。`tools/gen-stages.js --hard` / `--hard2` に条件を残してある。
- **警戒ゲージが見えない** → 原因: 盤の上ぶちに**同じマゼンタのネオン管**が引いてあり、
  ゲージが伸びても見分けが付かなかった。→ 地の線を暗い水色にして、ゲージだけを光らせた。
- **ワープゲートが「金色の樽」に見える** → 原因: 上に梁を渡し、足元に楕円を描いて**閉じた形**にしていた。
  → 上と下を開け、あいだを昇る光の柱にしたら門に見えるようになった。
- **ゲートが盤の上ぶちで切れる** → 原因: ゲートはマスより **上へ80px** 伸びるのに、上下の余白が同じだった。
  → `PADT 104 / PADB 56` と上だけ広くした。
- **PCで盤が画面より高くなる** → 縦長(2:3)なので幅で決めると 1440×900 ではみ出す。
  → `.wrap{max-width:min(760px, 50vh)}` と高さからも上限をかけた。
- **書き換えスクリプトが例外で止まり、直前の置換ごと消えた**（同じ失敗を2回）。
  → 原因: `p.write_text()` を最後にまとめて呼んでいたので、途中の assert で落ちると全部捨てられる。
  → 1か所ずつ書き込むようにした。**画面を見て「反映されていない」と気づけたのが救い**。

- **症状**: 猫を1マス動かすと盤面が固まり、ロボットが動かず操作も効かなくなる。
  **原因**: 跳ねている間の影を `17 - hop*4` と引き算で描いていて、`hop`（最大26）で**半径が負**になり
  `ctx.ellipse()` が `IndexSizeError`。**例外で `requestAnimationFrame` の輪が切れ、
  進行タイマー（描画ループの中で数えている）ごと止まっていた**。
  **直し方**: 影は掛け算で縮める（`Math.max(0.35, 1 - hop/44)`）＋**次のフレームを関数の先頭で予約**する。
  こうすると、この先どこかで描画が転んでもゲームは止まらない。
- **症状**: `va.sh` の Console に 404 が1件残る。
  **原因**: `favicon.ico`。**直し方**: タブのアイコンを data URI（SVGのネコ顔）で埋め込んだ → **エラー0件**。
