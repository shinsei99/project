## なぜこの文言なのか（先に読む）

**提出前に App Store を実測した**（2026-08-28・iTunes Search API・日本ストア）。
KeyTag が Guideline 4.3(a)（スパム＝他の開発者のアプリと似ている）で差し戻された教訓による。

| 調べたこと | 結果 |
|---|---|
| `にゃんこ大脱出` の完全一致 | **なし**（名前は空いている） |
| 近い名前 | **`ミケねこ大脱出`**（Masafumi Tsubo）が1本ある。ただし**壁を跳ね返って上へ登るジャンプアクション**で、遊びは別物 |
| 「猫 × 脱出」の棚 | **ほぼ全部が脱出ゲーム（部屋を調べて謎を解く点クリック）**。`迷い猫の旅` シリーズ／`猫様の学び舎からの脱出`／`Cat Escape!` など |
| 「ねこ 逃げる ロボット」 | **0件** |

**つまり「猫＋脱出」は脱出ゲーム（謎解き）の棚**で、本作はそこに属さない。
本作は**ターン制の追いかけっこパズル**（マス目のグラフの上を1マスずつ動き、敵は毎ターン
最短経路で1マス近づく）。謎解きもアクションも無い。**名前だけで棚を間違えられると 4.3 を踏む**ので、
サブタイトルと説明の1行目で「追いかけっこパズル」「1手ずつ」を先に言い切る。

| ✅ 前に出す | なぜ効くか |
|---|---|
| **ターン制。1手ずつ考える**（アクションでも謎解きでもない） | 近い名前のアプリ・同じ棚の脱出ゲームとの最大の違い |
| **敵は運で動かない。必ず最短経路で近づく** | 読み切れる＝実力のゲームだと分かる。量産の運ゲーとの違い |
| **全30面すべてに最短手数があり、★3はぴったりでクリア** | 総当たりで検証済みの数値。やり込みの軸 |
| **広告なし・課金なし・通信なし** | 同じ棚の無料ゲームはほぼ広告収益型。いちばん分かりやすい違い |
| **絵は外部素材ゼロ。canvas に手描き** | 量産アプリは素材集の使い回しが多い |

❌ 「脱出ゲーム」「謎解き」という語を主役にしない（自分から別の棚に入りに行くことになる）。

## 説明（4000字以内）

※ **App Store の説明に絵文字は入れられない**（にゃんこアイスで HTTP 409 `INVALID_CHARACTERS`）。以下は絵文字なし。

```
おじいちゃんの家から、おそうじロボットにつかまらないように逃げてください。
目ざすのはキャットタワー。全30ステージのターン制パズルです。

■ 1手ずつ、考えるゲームです
ねこはとなりのマスへ1マスずつ動きます。動いたらロボットの番です。
アクションではないので、いくら考えても大丈夫。時間制限はありません。

■ ロボットは運で動きません
毎ターン、かならず最短の道でねこへ1マス近づきます。
だから「どう動けば追いつかれないか」を先読みできます。運任せの場面はひとつもありません。
次にロボットが来られるマスは、赤い点線で盤面に表示されます。

■ 部屋のものを使って、遠回りさせる
・ソファ … ロボットは通れません。ねこだけの安全地帯です
・毛糸玉 … 乗ったロボットは1ターン動けなくなります
・おさかな … 取るとその番にもう1マス動けます
・落とし穴 … ロボットだけが落ちて退場します
・ねこのぬけ道（21面から）… ねこだけが通れる細い道
・スイッチとドア（21面から）… 踏むと閉じていた道が開きます

■ 最短手数に挑戦できます
30面すべてに最短手数が用意してあります。ぴったりの手数でクリアすると星3つ。
ステージ選択の画面で、どの面で星を取り逃しているか一目で分かります。

■ 安心して遊べます
・広告は出ません
・アプリ内課金はありません
・インターネットに接続しません（機内モードでも全部遊べます）
・アカウント登録も、個人情報の入力もありません
・クリア状況と星は端末の中だけに保存します

■ こんな方に
・子どもに考える遊びをさせたい（ひらがな中心の文で、読み書きの負担が少ないつくりです）
・短い時間で1面ずつ遊びたい
・運の要素がないパズルが好き
・広告で中断されるゲームに疲れた

絵はすべてその場で描いています（外部の画像素材は使っていません）。
書体は SIL Open Font License の Zen Maru Gothic を使用しています。
```
