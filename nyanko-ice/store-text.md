# App Store Connect に入れる文言（にゃんこのアイス屋さん）

そのままコピーして使えるようにしてある。文字数は App Store Connect の上限。
**流し込みは `python3 push-metadata.py --apply`**（この1ファイルを正とする。画面へ手で写さない）。

---

## なぜこの文言なのか（先に読む）

**提出前に App Store を実測した**（2026-08-28・iTunes Search API）。KeyTag が
Guideline 4.3(a)（スパム＝他の開発者のアプリと似ている）で差し戻された教訓による。

| 調べたこと | 結果 |
|---|---|
| `にゃんこのアイス屋さん` の完全一致 | **なし**（名前は空いている） |
| 同ジャンル（アイス×ソートパズル） | **量産アプリが多い**。`Icecream Sort Puzzle`（CHENGDU MIAOZHI TECHNOLOGY）／`Ice Cream Sort`（Indigo Bunting）／`アイスクリームの並べ替え`（Skilljoy）／`Ice Cream Matching Puzzle`／`Cake Sorting: Food Puzzle` など |
| 名前が近いもの | `ねこのアイスクリーム屋さん`（naoji kawaguchi）。**題材は近いが別ジャンル** |

**つまりここは 4.3(a) を踏みやすい棚。**「アイスを並べ替えるパズル」とだけ名乗ると、
量産群と同じ棚に並ぶ。そこで、量産群が**持っていないもの**を文言の中心に置く。

| ✅ 前に出す | なぜ効くか |
|---|---|
| **広告が出ない・課金がない・通信もしない** | 量産ソートパズルはほぼ全て広告収益型。**最も分かりやすい違い** |
| **絵を1枚ずつ手で描いている**（外部の画像素材は0枚・canvasに直接描画） | 量産群は同じ素材集の使い回しが多い |
| **「ちゅうもん」がある**＝ただ並べ替えるのではなく、指定された味を作る店番ゲーム | ソートパズルに接客の目的が乗る |
| **時間でアイスが落ちてくる**＝落ち物の緊張感 | 手番制のソートパズルと手触りが違う |
| **日本語で、ぜんぶ ひらがな中心** | 小さな子どもと一緒に遊べる |

❌ 名前や説明の主役を「ソートパズル」にしない（量産群の棚に自分から入る）。

## 説明（4000字以内）

> **★説明に絵文字を入れてはいけない。** 2026-08-28 に `🍦` を入れて API が
> HTTP 409 `INVALID_CHARACTERS`（`Description can't contain …`）で拒否した。
> 名前・サブタイトル・プロモ・キーワードでも同じと考えて、絵文字は使わないこと。

```
ねこ店長といっしょに、アイス屋さんを切りもりするパズルゲームです。

コーンをタップして、アイスをうつす。おなじ味を3つかさねると、そのコーンが売れて売上になります。
おきゃくさんの「ちゅうもん」どおりの味を作れば、ボーナスがもらえます。

アイスは、時間がたつと上から落ちてきます。うっかりしていると、コーンからあふれてゲームオーバー。
かんたんに見えて、ステージが進むほど落ちてくる間かくが短くなります。

■ このアプリの特ちょう

・広告が1つも出ません
　ゲームの途中で動画が始まったり、画面のはしにバナーが出たりすることはありません。

・アプリ内の課金がありません
　あとから何かを買う必要はありません。最初から最後まで、ぜんぶ遊べます。

・インターネットにつながりません
　機内モードでも遊べます。通信をしないので、情報が外に出ていくこともありません。
　集めているデータもありません。

・絵は1枚ずつ手で描いています
　できあいの素材集は使っていません。木の看板、丸まど、ペンダントライト、冷凍ショーケース、
　エプロンをつけたねこ店長。ぜんぶこのアプリのために描いたものです。

・文字はひらがな中心です
　小さなお子さんでも読めるようにしています。むずかしい操作もありません。
　タップ2回（えらぶ→おく）だけで遊べます。

■ 遊びかた

1. コーンをタップして えらぶ
2. おきたい場所を もう一度タップ すると、いちばん上のアイスが うつります
3. おなじ味が3つそろうと、そのコーンが売れます
4. 画面の左上の「ちゅうもん」の味を作ると ボーナス
5. アイスがあふれたら ゲームオーバー。「つづきから」で そのステージから 再開できます

■ こんなときに

・お子さんに、広告の出ないゲームを渡したいとき
・電車や飛行機の中など、通信ができないとき
・ちょっとした ひまつぶしに

音は、画面の右下のボタンで いつでも消せます。設定は次に遊ぶときも残ります。

ご質問・ご要望は、サポートページからお気軽にご連絡ください。
```

## 審査ノート（App Review への連絡事項）

```
このアプリについて

・アカウント登録、ログインは必要ありません。すべての機能が起動直後から利用できます。
・アプリ内課金、広告、外部サービスとの通信は一切ありません。
　サードパーティのSDKも組み込んでいません（バンドルに含まれるのは Capacitor のみです）。
・収集している利用者データはありません。端末内に保存しているのは、
　ステージの進み具合と、音のオン・オフ設定だけです。

Guideline 4.3 について（あらかじめのご説明）

App Store には、アイスクリームを題材にした並べ替えパズルが多数あることを承知しています。
本アプリは、それらのテンプレートや素材集を使用していません。

・グラフィックはすべて Canvas API で1つずつ描画しています。画像素材は1枚も使用していません。
　（店内、ねこ店長、ショーケース、アイス、コーンなど、すべて描画コードです）
・ゲームの中心は並べ替えではなく「注文された味を作る」ことです。
　さらに、時間経過でアイスが自動的に落下するため、手番制の並べ替えパズルとは
　操作感が異なります。
・広告および課金を一切実装していません。

ソースコードは下記で公開しています。上記が事実であることをご確認いただけます。
https://github.com/shinsei99/project/tree/main/nyanko-ice

ブラウザで実際に動作をご確認いただけます（アプリと同じHTMLです）。
https://shinsei99.github.io/project/nyanko-ice/
```
