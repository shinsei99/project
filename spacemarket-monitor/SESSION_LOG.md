### 発生したエラーと解決策

- **症状**: `public_check.py` が3施設とも `HTTP Error 308: Permanent Redirect` で落ちる。
  curl -L では取れるのに urllib では取れない
  **原因**: `www.spacemarket.com` は末尾スラッシュ無しのURLに 308 を返す。urllib の
  `HTTPRedirectHandler.redirect_request` は 301/302/303/307 しか許可せず、それ以外は
  HTTPError を投げる。**308 が許可コードに入るのは Python 3.11 以降**で、
  `agent-platform/.venv` は **3.9.6** だった
  **直し方**: `http_error_308` を足すだけでは不足（渡ってくる code が 308 のままなので
  `redirect_request` がまた弾く）。**コードを 307 に読み替えて** `http_error_307` に渡す。
  どのバージョンでも動く

- **症状**: レセプル福島・グリーンガーデン秋津のレビュー内訳が全項目 0 で出る
  **原因**: こちらの取得漏れではなく、**SpaceMarket が 0 を返している**（生データで確認）。
  総合点と件数は正しく返る。グリーンガーデン加東には内訳が入っている
  **直し方**: 0 を点数として並べると「評価0点」と誤読するので、レポートでは「—」表示にし、
  注記を出すようにした
