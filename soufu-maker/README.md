# 送付書メーカー（soufu-maker・port 8525）

**社員が使う送付書ツール。** 宛名と用件メモを入れると、`claude` CLI が本文を書き、
送付書を Word（.docx）で出力する。社内LAN共有あり（launchd `com.shinsei.soufu-maker`）。

## 送付書ジェネレーター（8518）との違い — 意図して2本に分けている

| | **このアプリ（8525）** | 送付書ジェネレーター（`soufu-generator`・8518） |
|---|---|---|
| 誰が使う | **社員**（社内LAN共有） | **オーナー個人**（社内には配らない） |
| 差出人 | 大京商事に**固定**。担当者（名前＋メール）だけ切替（`tantou.json`） | 4プロファイルから選ぶ（会社3つ＋個人） |
| バインド | `0.0.0.0` | `127.0.0.1` |

**統合しないこと。** 個人名義・自宅住所の差出人を社員の画面に出さないための分離。
共通部分を触るときは**両方**に同じ修正を入れる。

## 担当者マスタ

`tantou.json`（**gitignore**・名前とメールアドレス）。画面のサイドバーで追加・編集する。
会社情報（社名・住所・TEL・FAX）は app.py に固定で持っている。

## 起動

```bash
./run.sh          # http://0.0.0.0:8525（社内LAN共有）
```

`claude` の場所は `_find_claude()` が PATH → よくある場所の順に探す。
