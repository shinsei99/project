## 0. 前提（サブPCで済んでいること）

- コードは **push 済み**。`git pull` だけで届く
- `project.yml` / `PhotoRemake.xcodeproj` とも **1.1.0 / build 4** に更新済み
- Debug / Release ともビルド通過（警告0）、シミュレータで画面と書き出しPNGを目視確認済み
- **実機では未確認**（サブPCに配布証明書が無いため）。下の「2. 実機で触る」でやること

## 1. 取り込み〜ビルド番号の確認

```bash
cd ~ && git pull
./ios-build-guard.sh photo-remake        # 「✅ 衝突なし: 現在build 4 > 既存最大 3」と出ること
python3 appstore_api.py --review com.shinsei.photoremake   # 審査中のものが無いことを確認
```

> **`xcodegen generate` は実行しなくてよい。** `.xcodeproj` は生成済みでコミットしてある。
> 走らせると **Signing の Team 選択が消える**ので、やるなら Archive 前に選び直すこと。

## 2. 実機で触る（Archive の前に一度）

```bash
open ~/photo-remake/PhotoRemake.xcodeproj
```

Xcode で **Signing & Capabilities → Team を自分のものに**してから実機で実行し、次を確認する。
**今回の変更点がすべて指の操作**なので、ここだけは人が触らないと分からない。

- [ ] 下部パレット「**図形**」→ シートから **矢印・四角・星・吹き出し** などを追加できる
- [ ] 図形を**ドラッグで移動 / 右下ハンドルで大きさ / 右上ハンドルで回転**できる
- [ ] 「色」タブで **塗りと枠線を別々に**変えられる。左端の「**なし**」で塗りだけ／枠線だけ消せる
- [ ] 「種類」タブで **矢印 ⇄ 図形** を入れ替えても、位置と向きがおおよそ保たれる（↩︎で戻せる）
- [ ] 何か編集した状態で上部「**写真**」→ **確認ダイアログ**が出る。「編集を続ける」で消えない
- [ ] 「保存」→ カメラロールの画像が**画面で見たとおり**になっている（図形の位置・色・太さ）

## 3. Archive → アップロード

1. Xcode の実行先を **Any iOS Device (arm64)** にする
2. **Product → Archive**
3. Organizer → **Distribute App → App Store Connect → Upload**
4. アップロード後、App Store Connect の TestFlight に **build 4** が出るまで待つ（数分〜十数分）

## 4. App Store Connect での提出

1. 「**+ バージョンまたはプラットフォーム**」→ **1.1.0** を作成
2. **このバージョンの新機能**（下の文案をそのまま貼れる）
3. **ビルド**に build 4 を選ぶ
4. スクリーンショットは前バージョンのものが引き継がれる。
   **図形機能を見せたいなら差し替える**（必須ではない）。寸法は iPhone 1284×2778 / iPad 2048×2732。
   新しめのシミュレータの解像度（1206×2622 等）は弾かれるので `sips` でリサイズすること
5. 「審査へ提出」

### このバージョンの新機能（貼り付け用）

```
・写真に図形を入れられるようになりました。矢印・四角・角丸・丸・三角・ひし形・五角形・六角形・星・ハート・吹き出し・十字・バツの全13種類から選べます。
・図形は塗りの色と枠線の色を別々に指定でき、それぞれ「なし」にもできます。大きさ・回転も自由に変えられます。
・「種類」から矢印と図形をあとから入れ替えられるようにしました。
・編集中に「写真」ボタンを押したときに確認をはさむようにしました。うっかり押しても編集内容が消えません。
```

## 5. 提出後

```bash
python3 appstore_api.py --review com.shinsei.photoremake   # 審査状況を見る（画面を見に行かなくてよい）
```

配信が始まったら **`CLAUDE.md` のアプリ一覧（フォトリメイクの行）と `photo-remake/TODO.md` を
