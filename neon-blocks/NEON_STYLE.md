# ネオンシリーズ 共通の型（6本）

**なぜ要るか**: 6本は `neon-blocks` の1つのアプリに同居し、下の帯で行き来する。
遊びの中身は違ってよいが、**入口・字面・音・音ボタンの位置が違うと「別のアプリに来た」と感じる**。
2026-08-29 に実測したところ、揃っていたのは「暗い地」「名前」「切り替え帯」の3つだけだった。

**このファイルが正**。各ゲームを触るときは、ここに合わせること。

---

## 1. 配色（共通5色）

| 用途 | 色 | 使いどころ |
|---|---|---|
| 主 | `#41E3FF`（シアン） | 枠・道・味方・進む方向 |
| 副 | `#FF4FC3`（マゼンタ） | 敵・危険・決定ボタン |
| 強調 | `#FFD54F`（金） | 得点・ゴール・報酬 |
| 成功 | `#7CFF4F`（緑） | 可能・達成・HP |
| 補助 | `#B36BFF`（紫） | 設定・その他 |

地は `#0A0720`〜`#241247`（夜）。**面は暗く、輪郭を光らせる**（塗りつぶさない）。

> **ゲーム固有の色は残してよい**（ブロックスの多色ブロック、グラビティの惑星など）。
> 揃えるのは**枠・ボタン・文字・HUD**。中身の絵まで同じ色にすると見分けが付かなくなる。

## 2. 書体

- 日本語 … **Zen Kaku Gothic New**（500 / 900）
- 英数字 … **Orbitron**（700 / 900）
- どちらも SIL OFL。**使う文字だけ同梱**（各アプリの `tools/fetch-font.py`）
- 指定は必ず `Orbitron,"Zen Kaku Gothic New",sans-serif` の順（英数字が Orbitron に落ちる）
- **丸ゴシックは使わない**（幼く見える）

## 3. 入口（タイトル画面）

**6本すべてに全画面のタイトルを出す。** 中身は次の4つだけ。

1. 日本語の題名（大・発光）＋ ラテン表記（小・マゼンタ）
2. 1行の説明
3. **START**（マゼンタのネオン管・押せることが分かる明るさ）
4. 副ボタン（ステージ選択・図鑑など。無ければ省く）

## 4. 音ボタン

**画面の右上に固定**。48×44px 程度、暗い地＋シアンの縁。設定画面の中に隠さない。
状態は各アプリの localStorage に持つ（キーはアプリごとで可）。

## 5. 音

**同じ楽器・同じ音階・違う調**。これで「同じシリーズの別の曲」に聞こえる。

- 音量: `master 1` → `sfx 0.9` / `bgm 0.24`（±0.04まで）
- BGM: **メジャーペンタトニック（0,2,4,7,9）**のみ。メロディ=`triangle`、ベース=`sine`
- 効果音: 短い `voice()`＋`noise()`。**同じ出来事には同じ音**（取得＝上がる3音／失敗＝下がる2音）
- **調はゲームごとに変える**（下の表）。テンポは遊びに合わせて自由

| ゲーム | 調 | もとの調 | 基準音（実装での定数） |
|---|---|---|---|
| ネオンブロックス | **A** | A（据置） | MIDI 57=A3 / 45=A2（`ARP` / `BASS`） |
| ネオンサイボーグ | **D** | A から移す | ベース `A2 110` → `D3 146.83` |
| ネオンタワー | **E** | C から移す | 各トラックの Hz を **×1.2599**（+4半音） |
| ネオングラビティ | **G** | A から移す | `110` → `98.00`、`220` → `196.00` |
| ネオンアイス | **C** | C（据置） | メロ `523.25` / ベース `130.81` |
| ネオンエスケープ | **F** | C から移す | メロ `698.46` / ベース `174.61` |

## 6. 画面の向き

**縦持ち**に統一する（スマホで遊ぶため）。盤の縦横比はゲームごとでよいが、横長にしない。

## 7. その他

- **favicon を必ず入れる**（data URI で埋め込む。外部ファイルにすると 404 が Console に残る）
- 下の切り替え帯（`www/games/_switch.js`）は**触らない**。各ゲームは読み込むだけ
- 直したら `python3 neon-blocks/tools/sync-games.py` で集合側へ入れ直す
