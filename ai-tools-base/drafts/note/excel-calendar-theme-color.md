# 1月だけ、休みの日が消えていた

社内のチャットに常駐しているAIに、「**会社の休みの日には動かない**」という条件を付けています。
休みの日に日報を作ったり、担当者に催促を送ったりしないためです。

会社の休みは、年間の休暇スケジュールというExcelにまとまっています。
1枚のシートに1か月ぶんのカレンダーが並んでいて、**休みの日のマスがオレンジに塗ってある**。
よくある表です。人が見れば一目で分かります。

これを機械に読ませたら、三段階でつまずきました。

## その一。色が、取れない

まず、オレンジのマスを数えさせました。**0件**でした。

エラーは出ません。「1件も塗られていません」と静かに答えるだけです。

調べてみると、Excelの色には二通りの入り方がありました。

- **色そのものを保存する塗り方**（この色、と決めて塗る）
- **番号だけを保存する塗り方**（テーマの5番目の色、という控え方）

このカレンダーは後者でした。ファイルの中を開いても、オレンジという情報はどこにもない。
「5番目」としか書いていないのです。実際の色は、そのファイルが持っているテーマ側にあります。

つまり、**見えている色と、保存されている中身は別物**でした。
テーマを差し替えれば、同じ「5番目」のまま見た目だけが変わります。

番号のほうを見るように直したら、ようやく数えられるようになりました。

## その二。塗ってあるのは、日付の下の段だった

次は、日付は取れるのに、休みかどうかが合わない。

こちらは単純な話で、**1日ぶんのマスが上下2段でできていました**。
上の段に日付の数字、**下の段に色**。罫線で囲まれているので、人の目には1つの枠に見えます。

人は枠として見る。機械は別々のマスとして見る。この差でした。

## その三。1月だけ0件

ここが本題です。

12か月ぶんを取り込んで、月ごとに数えてみたら、**1月だけが0件**。他の11か月は正しく取れていました。

原因は、カレンダーの外にありました。

見出しの上に、「何月か」を示す数字が小さく置いてあったのです。
1月のシートでは、その数字が **1**。

機械はこれを「**1日**」と読みました。そこから1か月が始まったと思い込み、
次に出てくる数字（前の月の末日の 28）を見て「日付が飛んだ、月が終わった」と判断し、
**そこで読むのをやめていました**。だから0件です。

たちが悪いのは、8月のシートでは同じ場所に **8** と書いてあることでした。
8は1日ではないので、素通りします。**1月でしか起きない**わけです。

直し方は、「何行目から読む」と決め打ちするのをやめて、
**曜日の見出し（日 月 火 …）を先に探し、その下だけをカレンダーとして読む**ことでした。

## なぜ気づけたか

年間で **106日** が取り込めていました。数字としては、いかにも正しそうです。
祝日と土日を足せばそれくらいになります。

気づけたのは、**月ごとに分けて数えたから**でした。
合計だけを見ていたら、たぶんそのまま使っていたと思います。

そして、1月に休みが無いことに現場が気づくのは、**年が明けてから**です。

## 人が見るための表を、機械に渡すとき

この件でいちばん覚えておきたいのは、次のことです。

- 人向けの表は、**線と色と位置**に意味が載っている
- その意味は、**ファイルの中には書かれていない**
- 「休み」と書いてある表なら何も起きなかった。**書いていないから起きた**

だから、こういう表を機械に渡すときは、
**合計ではなく、0件になりうる単位（月ごと、シートごと）で数えて並べる**ようにしています。

いちばん安い検査で、いちばんよく引っかかります。
