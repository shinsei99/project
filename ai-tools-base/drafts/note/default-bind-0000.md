# 自分だけのつもりの画面が、社内の全員から見えていた

事務所のMacで、自作の道具を30本ほど動かしっぱなしにしています。
社員はブラウザのお気に入りから開くだけで使えます。

この30本には、二種類あります。

- **社内で共有するもの**（見積書の作成、物件の案内文、駐車場の空き状況など）
- **自分だけで使うもの**（個人の資産の管理、買取のDM作り）

後者は、社内に配っていません。共有フォルダにも入れていません。
自分のMacの中だけで開くもの、のつもりでした。

**そのつもりだった2本が、社内の誰からでも開ける状態になっていました。**

片方は、**個人の保有資産の明細**が並ぶ画面です。

## 「ローカルで起動」と書いてあった

起動の手順を書いたファイルには、こう書いてありました。

```
# localhost で起動（社内共有しない）
```

意図は間違っていません。書いた本人（私です）は、そのつもりでした。

問題は、**そう書いただけで、そう指定していなかった**ことです。

使っている道具には、「どこからの接続を受けるか」を指定する設定があります。
それを**書かなかった場合、どうなるか**。

私は「書かなければ、自分のパソコンの中だけ」だと思っていました。
実際は逆で、**書かなければ、どこからでも受ける**設定でした。

## 調べるのは1行

いま何がどこで待っているかは、コマンド1行で分かります。

```
python3  1234  ...  TCP *:8527 (LISTEN)          ← どこからでも
python3  5678  ...  TCP 127.0.0.1:8503 (LISTEN)  ← このMacの中だけ
```

頭が `*` になっていたら、社内のどのパソコンからでも開けます。
`127.0.0.1` なら、このMacの中だけです。

見たら、資産の画面が `*` でした。

## 数日後、別の道具でも同じことが起きた

直した数日後、まったく別の仕組みで作った画面でも、同じことが起きました。

そちらも、**指定しなければ全部から受ける**設定でした。
「これは開発用の画面だから、手元だけだろう」というのも、思い込みでした。

## 直し方は「省略しない」

いまは、**共有するものも、しないものも、必ず書く**ようにしています。

共有するものまで書く理由は、次に読む人のためです。

書いていないと、「分かっていて省いたのか」「知らずに省いたのか」が分かりません。
書いてあれば、それが意図だと分かります。

## 直しても、閉じていなかった

もう一つ、ここでつまずきました。

起動の手順を直したのに、**動いているものは変わりませんでした**。

調べたら、動かしっぱなしの設定が、その手順を通らずに、直接プログラムを呼んでいました。
手順書は、手で起動するときにしか使われていなかった。

**「直した」と「そうなった」は、別のことです。**
設定を入れ直して、もう一度、待ち受けを見るまでが一組でした。

## 最後は、別のパソコンから開いてみる

いまは、点検をこの順でやっています。

1. 設定に何が書いてあるかを見る
2. いま実際にどこで待っているかを見る
3. **別のパソコンから開いてみて、繋がらないことを確かめる**

3番目まで見る理由は、1と2は「そう書いてある」の確認でしかないからです。

**開こうとして開けないことを、実際に見て、はじめて閉じたと言えます。**

社内の道具は、便利になるほど本数が増えます。
本数が増えるほど、「たぶん大丈夫」で済ませたくなる。そこが危ないところでした。
