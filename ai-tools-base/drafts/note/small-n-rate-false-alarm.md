# 「50%に落ちています」。中を開けたら、2件のうち1件でした

時間貸ししている区画の予約実績を、自動で診断する道具を作りました。

実績が落ちたときに、原因を会議で当てにいくのをやめたかったからです。
「値段が高いのでは」「対応が遅かったのでは」「そもそも見られていないのでは」。
毎回この3つを、勘で言い合っていました。

## 道具に何をさせたか

落ち込みの原因は、大きく2つに分かれます。

- **入口の問題** … そもそも見つけてもらえていない。問い合わせ自体が来ていない
- **取りこぼしの問題** … 問い合わせは来ているのに、成約まで持っていけていない

この2つは、打つ手がまったく違います。
前者なら掲載の見せ方や広告、後者なら返答の速さや条件面です。
どちらなのかを、数字から自動で言い切らせることにしました。

## 出てきた警告

レポートにこう出ました。

- 申込 9件 → 2件
- 成約の歩留まり **100% → 50%**
- 判定：**来た話を取りこぼしている**

半分に落ちている。これは大ごとです。

中を開けました。今年の申込は **2件**。そのうち **1件が、まだ保留のまま**でした。
それだけです。取りこぼしてなどいません。その1件が動けば、また100%に戻ります。

## なぜこうなったか

**割合を出した瞬間に、元が何件だったかが消えるから**です。

- 9件のうち9件 → 100%
- 2件のうち1件 → 50%

並べれば「半減」に見えます。けれど後者は、**たった1件の保留**でできた数字です。

しかもこの手の判定には、意地の悪い性質があります。

**母数が小さいほど、変化が大きく出る。**

2件のうち1件が動けば50ポイント。9件のうち1件なら11ポイント。
つまり、**いちばん情報が少ないところで、いちばん大きな警告が鳴る**わけです。
これでは、鳴ったところで何もできません。

## 直したこと

線引きを厳しくする方向では直りませんでした。
2件のうち1件は、何ポイントに設定しても跳ねてしまうからです。

そこで、判定に**下限**を持たせました。

- 比べる2つの年の、**どちらかが10件に満たなければ、割合の判定を出さない**
- 代わりに「この区画は、件数そのものを見てください」と書かせる

ここで大事だったのは、**黙って飛ばさなかった**ことです。
何も書かずに済ませると、読む人は「異常なし」と受け取ります。
それは別の嘘になります。**判定しなかったことも、理由をつけて書く。**

似た穴がもう1つありました。
リピートのお客様が **0人から0人**のままの区画に、
「リピートは保たれています。満足度の問題ではありません」と出ていたのです。

0人が0人のままなのは、維持ではありません。**まだ何も分かっていない**が正しい。
こちらも、どちらかの年に3件以上あるときだけ言うようにしました。

## 誤警報を消したら、本題が言えた

ここを直したことで、実績の十分ある区画については、はっきり言い切れました。

- 申込 43件 → 20件（半分以下）
- **けれど歩留まりは 74% → 90% に上がっている**（来た話は、前よりちゃんと決まっている）
- **リピートのお客様は 7件 → 7件で、1件も減っていない**
- 減ったのは、**新規のお客様だけ**（25件 → 11件）

接客が悪くなったなら、歩留まりが下がるはずです。上がっています。
満足度が落ちたなら、常連が減るはずです。減っていません。
**残るのは「新しい人に見つかっていない」だけ**でした。

別の区画でも同じ形でした（申込 15件 → 11件、歩留まり 73% → 82%）。
勘で言い合っていた3つの見立てが、消去法で1つに絞れたことになります。

## この件から持ち帰ったこと

**割合は、元の件数を添えないと、事実を伝えません。**

「50%落ちた」は、9件が4件になったのか、2件が1件になったのかで、意味がまるで違います。
けれど数字の見た目は同じです。

そして**数字が少ないものほど、派手に動きます**。
実績の小さい区画、始めたばかりの取り組み、めったに使われない機能。
そういうところほど大きな警告が出て、しかもその警告は、たいてい何も意味していません。

線引きを厳しくする前に、**「そもそも何件あったら口を出してよいか」を決める。**
これが先でした。
