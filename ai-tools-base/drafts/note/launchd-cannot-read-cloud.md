# 手で起動すれば読めるのに、自動で起動すると読めない

紙の書類を、スマホで撮ってクラウドのフォルダへ送り、
事務所のMacがそれを取り込んで整理する、という運用をしています。

現場で受け取った書類を、事務所に戻る前に片付けられるので、便利に使っていました。

この取り込みが、**Macを自動起動の設定にした途端、動かなくなりました**。

## 同じフォルダなのに、読めない

エラーの内容は「そのフォルダを見る権限がありません」というものでした。

おかしいのは、**手で起動すれば読める**ことです。
同じMac、同じユーザー、同じフォルダ、同じプログラム。
起動のしかたを変えただけで、読めたり読めなかったりする。

## 権限を与える相手を、間違えていた

Macには、写真・連絡先・書類など、**アプリが勝手に見てはいけない場所**があります。
クラウドの同期フォルダも、そのひとつです。

見せてよいアプリには、設定で許可を与えます。
私は「このプログラムに許可を与えればいい」と考えて、
プログラム本体を許可の一覧に追加しました。

**効きませんでした。** 何度やっても、読めないままです。

原因は、**許可を判定される相手が、そのプログラムではなかった**ことでした。

自動起動の設定は、まず「起動用の小さな手順書」を実行して、その中からプログラムを呼びます。
Macは、**最初に実行されたほう**を見て、許可があるかどうかを判定していました。

つまり、許可を与えるべき相手は、プログラムではなく、**その手前で起動しているほう**だった。

手で起動したときに読めたのも、同じ理屈でした。
手で起動するときは、ターミナルという別のアプリが親になります。そちらは許可を持っていたのです。

**「手で起動すると読めるのに、自動だと読めない」** は、この問題の目印になります。

## 権限が無いだけで、全部止まっていた

もう一つ、直したことがあります。

取り込みフォルダが読めないだけで、**アプリの画面全体がエラーで止まっていました**。

書類の検索も、手入力での登録も、保管場所の確認も、
クラウドとは何の関係もないのに、まとめて使えない状態でした。

いまは、取り込みの部分だけ止めて、こう出します。

> 取込フォルダを読み取れません（設定が必要です）。検索・手入力での登録は、このまま使えます。

**動かない部分は動かないと言い、動く部分は動かす。**
まとめて止めてしまうと、「アプリが壊れた」という話になって、誰も使わなくなります。

## 途中で権限を失うこともある

別の道具では、もっと分かりにくいことが起きました。

起動したときは読めていたのに、**しばらく動かしているうちに読めなくなる**。
Macの側の判定が、動作中に変わることがあるようです。

こちらは、権限のエラーが続いたら**自分で終了して、起動し直す**ようにしました。
自動起動の設定は、落ちたら勝手に立ち上げ直してくれるので、それに任せる形です。

ここで大事なのが、**回数の上限**でした。うちは「30分で5回まで」。

上限が無いと、権限が戻らないときに、延々と再起動を繰り返します。
記録が埋まって、本当の原因が見えなくなる。「自分で直る仕組み」は、
**止まるところまで決めて、はじめて仕組みになります。**

## 便利にするほど、権限の話が増える

クラウドを使う、スマホから送る、自動で取り込む。
どれも便利になる方向の話ですが、便利にするほど、**この種の「見えない壁」に当たります**。

しかも、たいていエラーの文面は素っ気ないので、何が悪いのか分かりません。

この件で覚えたのは、**「誰がやろうとしたことになっているのか」を疑う**ということでした。
プログラムが読もうとしているように見えても、Macから見た主語は、別のものかもしれません。
