# 1人のAI社員が、2つの会社の書類を持っている

社内のチャットに、AIを常駐させています。質問すると、社内の書類を探して答えてくれる係です。

このAIは、2つの会社の書類を持っていました。ひとつは全社が入っているチャットの会社。
もうひとつは、別の会社の担当者と1対1でやりとりしているチャットの会社。

入口は違いますが、**AIが見ている書類の棚は1つ**でした。

つまり、片方のチャットで質問すると、もう片方の会社の書類が出てきます。
「絶対に混ぜないでほしい」と言われて、作り直した記録です。

## 「見ないでください」とお願いするのをやめた

いちばん簡単なのは、AIへの指示文に一行足すことです。

> この場では、もう一方の会社の資料に触れないでください。

これはやめました。理由は2つあります。

- **守られたかどうかを、あとから確かめられない。** 全部の返事を読む以外に方法がない
- **見えているものは、いつか出る。** 直接答えなくても、要約や「関連しそうな資料」の形で顔を出す

かわりに、**そもそも見えなくする**ことにしました。
書類の1件ごとに「どちらの会社のものか」を持たせ、探す段階で片方を落とします。

**見えないものは、漏らしようがありません。**

法令や判例、書籍だけは「共通」という扱いにして、どちらからも見えるようにしました。
これは会社の情報ではないからです。

## 壁を入れた直後、効いていないように見えた

作ってすぐ確かめたら、両方の入口から**同じ12件**が出てきました。効いていない。

調べたら、**確かめ方のほうが間違っていました。**

こちら側は「どのチャットからの質問か」を伝えていたのに、
AI側は「どちらの会社か」という別の情報しか見ていませんでした。
どちらも受け取れないので、両方とも初期設定の会社として扱われていた、というだけの話です。

ただ、これは同時に**作りの弱さ**でもありました。
片方の情報が届かないだけで壁が緩むなら、いつか本当に緩みます。

そこで、会社を判断する場所を**1か所にまとめました。**
会社名が届いていればそれを使う。無ければチャットの対応表から引く。それも無ければ初期設定。
**どちらか片方しか届かなくても決まる**ようにしました。

## 入口をふさいだつもりが、裏口が空いていた

次に出たのがこれです。

書類を探す道が、実は**2本**ありました。人と会話しながら探す道と、
AIが自分の判断で道具として探す道。この2本は、中で別々の仕組みを使っていました。

先に直したのは会話のほうです。裏の道は直っていないので、
そちらから探すと、**もう一方の会社の書類が10件出てきました。**

両方に同じ壁を入れて、ファイルの先頭に「もう一方にも同じ壁がある」と書き残しました。
片方だけ直して安心するのが、いちばん危ないからです。

## 書類を「入れるとき」の穴

もうひとつ、見落としていたところがあります。

書類に「どちらの会社か」の印を後から付けたとき、
**印が無いものは、とりあえず既存の会社のもの**という初期設定にしました。
すでに入っている書類はすべてその会社のものだったので、ここまでは正しい判断です。

問題は、**新しく取り込むときにも印を付けていなかった**ことです。

結果、もう一方の会社のフォルダを取り込んでも、既存の会社の書類として棚に入りました。
探す側の壁は正しく効いています。効いた上で、**中身のほうが間違った側に並んでいた**わけです。

出口をふさぐだけでは足りませんでした。**入口にも同じ判断が要ります。**

## 「ありません」と「お見せできません」は違う

AIが他社のものを触ろうとしたとき、何も返さない作りにしかけました。
これもやめました。

何も返さないと、AIは「該当する資料は無い」と受け取って、そのまま話を進めます。
「無い」と言われた人は、探すのをやめてしまいます。

いまは、こう返します。

> 別の会社のものなので、ここからは扱えません。その会社の入口で扱ってください。

**存在しないことにするのではなく、扱えないと言う。** 人が次に何をすればいいか分かります。

## 確かめ方を、言葉から数に変えた

最後に、本当に混ざっていないかをどう確かめたかです。

はじめは、片方の会社にしか無いはずの言葉で検索して、出てきたら漏れ、という方法をとりました。
ある許可の名前で引いたら、1件出ます。漏れかと思いました。

違いました。**その言葉は、もう一方の会社の書類にも普通に書いてあった**だけです。
言葉が出てくることは、その会社のものである証拠になりません。

やり方を変えて、**入口ごとに、見えている書類を会社別に数えました。**

- 全社のチャットから … 自社 4,378件、共通 262件、他社 **0件**
- 個人のチャットから … 自社 314件、共通 262件、他社 **0件**

共通の262件が両方で同じなのも、狙いどおりです。

**0という数字を出せる形にしておく。** これなら、次に棚を触ったときも同じ確認ができます。
「たぶん大丈夫」ではなく、毎回0を見る。それが壁を保つということでした。
