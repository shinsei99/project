# 夜中に働くはずのAIが、一晩なにもしていなかった

事務所のMacは、夜のあいだも働いています。

管理している建物の点検報告書や請求書は、紙で届いてスキャンされ、
画像のままのPDFとしてフォルダに溜まっていきます。画像なので、そのままでは検索に引っかかりません。

そこで毎晩1時から、AIがその画像を1枚ずつ見て、書いてある文字を起こし、
あとから検索できる形にしています。人が寝ているあいだに進む、地味な作業です。

ある朝、その晩の成果が **0件** でした。

## 「たぶんこれが原因です」と書いてあった

記録にはこう残っていました。

- 深夜1時に開始
- 0.3分で打ち切り
- 処理できた書類は0件
- 打ち切りの理由は「利用枠切れの可能性」

AIには月あたりの利用枠があります。枠を使い切ったのだろう、と思いました。

**この判断が間違いでした。** そして、間違いに気づくまで半日かかりました。

## 手でやらせたら、普通にできた

念のため、夜に失敗した5件を、朝に自分の手で流してみました。

普通に読めました。5件とも、1件も落ちずに。

同じパソコン、同じプログラム、同じ書類です。違いは1つだけでした。

**夜は「自動で」動いていて、朝は「私が」動かした。**

## 自動で動くときだけ、道具の場所が分からない

パソコンには「よく使う道具がどの引き出しに入っているか」を書いたメモのようなものがあります。
人がターミナルを開くと、そのメモは自動的に渡されます。

ところが、**夜中に自動で立ち上がる仕組みには、そのメモが渡っていませんでした。**

AI本体の場所は、プログラムの中に直接書いてあったので、呼び出せていました。
実際、AIはちゃんと書類を読んで、答えを返していました。

問題は、**AIが仕事を終えたあとの後片付け**でした。

その後片付けは、別の小さな道具を使います。その道具の場所はメモを見ないと分かりません。
メモが無いので見つからない。後片付けに失敗する。
すると、**「この仕事は失敗しました」という合図を残して終わってしまう**のです。

読み取り自体は、成功していたのに。

呼び出した側は、その合図だけを見ていました。だから「AIが落ちた」と判断しました。

## 手でやると再現しない

これがいちばん厄介でした。

自分の手で動かすとメモが渡るので、**何も起きません。**
「手ならできるのに、自動だとできない」という形でしか現れない。

原因は1行で直りました。夜中に自動で走る側にも、道具の場所を書いたメモを渡すだけです。
そのうえで、もう一度**自動の経路で**流して、ちゃんと読めることを確かめました。

## 本当に怖かったのは、別のところ

ここまでなら、一晩ぶんの仕事が飛んだだけの話です。実際には、もっと悪いことが起きていました。

このプログラムには、こういう仕組みがあります。

- 何度読ませても文字が取れない書類（白紙や、絵しか写っていないもの）がある
- そういう書類を毎晩やり直すのは無駄なので、**「見送り」として記録し、次からは飛ばす**

理屈は正しいです。ただ、この仕組みには落とし穴がありました。

**「AIが落ちていて読めなかった」と「この書類には文字が入っていない」を、区別していなかった**のです。

どちらも「文字が取れませんでした」という同じ形で返ってきていました。

つまりあの晩、たまたま順番が回ってきた5件の書類は、
**AIが落ちていたというだけの理由で「文字の無い書類」に分類され、以後ずっと対象外**になるところでした。

誰にも見えない形で、検索できない書類が増えていく。
その日の障害なら誰かが気づきますが、こちらは**気づく人がいません。**

いまは分けてあります。

- 読ませてみたけれど本当に文字が無かった → 見送りに入れる
- AIそのものが動かなかった → **見送りに入れない**（書類のせいではないので）
- AIが動かない状態が3回続いたら、その晩はきれいに諦める

## 学んだこと

**推測を、事実のような顔で書き残さない。**

あの「利用枠切れの可能性」という一言は、以前の自分が善意で書いたものでした。
親切のつもりが、翌朝の自分を半日ぶん、間違った方向へ連れて行きました。

いまは、実際に返ってきたエラーの文章をそのまま残しています。読みにくくても、そちらが事実です。
推測を書くなら、事実の後ろに置く。

もう一つ。

**「一時的な失敗」が「永久的な除外」に変わる場所は、どこかに必ずある。**

効率のために作った「もう見なくていいリスト」は、
入れる条件を1つ間違えるだけで、静かに仕事を減らす装置になります。

夜のあいだに動くものは、朝の数字でしか様子が分かりません。
だから数字が「0」だった日は、理由を最後まで見たほうがいい、と改めて思いました。
