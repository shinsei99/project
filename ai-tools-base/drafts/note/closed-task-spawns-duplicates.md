# やることリストが、毎日ひとりでに増えていく

会社のチャットに、AIを常駐させています。

やっているのは、会話を読んで「やること」を拾い上げることです。
「〇〇の見積り、明日までにお願いします」と誰かが書けば、それをリストに足す。
「終わりました」と報告があれば、そのリストの該当する行を閉じる。
人が入力しなくても、やることリストが勝手に整う——そういう仕組みです。

しばらく順調に動いていました。ある日、リストの様子がおかしいことに気づきました。

**同じような行が、いくつも並んでいるのです。**

## 増えていたもの

管理物件を回る担当者がいます。
建物の外を見て、写真を撮って、チャットに送る。「〇〇を巡回しました」と一言添えて。

その1件ごとに、AIが**新しい「やること」を作っていました。**

誰も頼んでいません。むしろ、すでに終わった仕事の報告です。
それが「これからやること」として、毎回リストに積まれていました。
記録に残っているだけで十件以上。担当者が真面目に回れば回るほど、
リストが伸びていくという、逆さまの状態でした。

## AIが間違えたのではなかった

最初は、AIの読み取りが下手なのだと思いました。
「巡回しました」という過去形を、依頼と読み違えているのだろうと。

調べたら、違いました。

この仕組みは、判定のたびに**「いま抱えている、終わっていない仕事の一覧」をAIに見せています。**
重複を防ぐためです。「この一覧の中に該当するものがあれば、新しく作らずにそこへ紐付けなさい」と。

そして担当者には、**「担当物件の巡回・確認」というまとめ役の1行**が登録してありました。
巡回の報告は、全部この1行に集まるはずでした。

そのまとめ役の1行が、**いつのまにか「完了」になっていました。**
何件かの物件の報告を受けた時点で、全体が終わったものとして処理されていたのです。

一覧に載るのは、終わっていない仕事だけです。
完了になった行は、そこから消えます。つまり——

**AIから見て、まとめ役の行は、最初から存在しなかったことになっていました。**

## 増やしていたのは、善意の保険だった

もうひとつ、以前に足した決まりがありました。

- 報告された仕事が、一覧のどれにも当てはまらないとき、黙って捨てないこと
- 見つからないなら、新しい行として記録し、「もう終わっている」という状態を入れること

これは、報告が記録に残らず消えてしまう問題を直したときの決まりです。
**捨てるくらいなら残そう**、という判断でした。いま見ても、間違っていたとは思いません。

さらに、こういう決まりもありました。

- 1つのメッセージに複数の物件の話が書かれていたら、物件ごとに分けて記録すること

この2つが、まとめ役の消失と噛み合いました。

1. まとめ役が一覧から消える
2. 巡回報告の行き先が無くなる
3. 「物件ごとに分けなさい」で、報告が物件の数だけ分裂する
4. 「見つからないなら新しく作りなさい」で、その全部が新しい行になる

**AIは、一度も間違った判断をしていません。**
渡された一覧の中で、決まりのとおりに動いただけです。
壊れていたのは、一覧の作り方のほうでした。

## 直したこと

決まりを1つ足しました。

- 写真だけ、あるいは写真と一言だけの**定例の巡回報告は、それ自体を新しい仕事にしない**
- まとめ役の行があれば、物件名がぴったり一致しなくても、そこへ「進みました」として紐付ける
- まとめ役が見当たらないときは、**何もしない**
- ただし、破損や不法駐輪など**対応が要る問題が見つかったときだけ**、その対応を新しい仕事にする

最後の1行が肝です。「巡回しました」は仕事ではありませんが、
「壁が割れていました」は仕事です。ここを一緒くたにすると、今度は必要な行が起票されなくなります。

直したのは文章15行だけで、プログラムそのものには手を入れていません。
実際のメッセージを使って、直す前と直した後で結果が変わることを確かめました。

## 分かったこと

**AIに見せる一覧は、単なる材料ではなく、AIにとっての世界そのものです。**
そこに無いものは、AIにとって存在しません。
「終わったから一覧から外す」という、人間には当たり前の処理が、
AIから見ると「その仕事は最初から無かった」に化けます。

そして、**「見つからなかったら、とりあえず作る」という保険は、
見つからない状態が続く設計と組み合わさると、増殖装置になります。**
保険をかけるときは、**どこまでが保険の対象なのか**まで書いておく必要がありました。

実は、同じ形の失敗を前にも踏んでいます。
そのときは逆向きで、一覧に載らない行への報告が、**黙って消えていました。**
増えるか、消えるか。出方は逆でも、原因は同じ「一覧から1件抜けていた」でした。

出力がおかしいとき、AIの頭を疑う前に、**何を渡していたか**を先に見る。
今回いちばん高くついた学びは、それでした。
