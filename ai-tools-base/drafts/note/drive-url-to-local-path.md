# 「そのフォルダはありません」と言われた。でも、そこにあった

事務所では、物件の資料をクラウドの共有フォルダに置いています。

契約書、写真、図面、点検の報告書。物件ごとにフォルダがあって、
「この物件の件です」と誰かに伝えるときは、そのフォルダのURLをチャットに貼ります。
住所を打ち込むより速いし、間違いようがないからです。

チャットには、社内資料に答えるAIも入っています。
URLを貼れば、AIが中を見て「この物件の資料は10件あります」と教えてくれる。そういう作りにしていました。

ある日、そのAIがこう答えました。

**「そのフォルダは存在しません」**

## AIは、それらしい理由まで付けてきた

ただ「ありません」とだけ言われたなら、私も貼り間違いを疑ったと思います。

ところがAIは、こう続けました。

- 同期されていない別のフォルダではないでしょうか
- ゴミ箱に入っている古いもののURLかもしれません

どちらも、いかにも本当らしく聞こえます。私もその線で調べて、
「およそ4万件ぶんのフォルダを探しましたが、見つかりませんでした」と報告しました。

**そのフォルダは、パソコンの中に、普通にありました。**

同期もされていたし、ゴミ箱にも入っていませんでした。
AIも私も、揃って間違った説明をしていたことになります。

## 原因は「名札を1枚しか見ていなかった」こと

クラウドのフォルダには、人が見る名前とは別に、機械が使う長い記号が付いています。
URLに入っているのはこの記号のほうです。いわば名札です。

パソコンに同期されたフォルダにも、その名札が控えとして書き込まれます。
だから、URLの名札と、手元のフォルダの名札を突き合わせれば、
「これだ」と分かるはず——そういう作りにしていました。

ここに落とし穴がありました。

**クラウド側は、同じフォルダに名札を何枚も持たせることがあるのです。**

フォルダを作り直したり、別の場所へ移したりすると、古い名札と新しい名札が両方生き続けます。
どちらのURLを開いても、ちゃんと同じフォルダが開きます。人から見れば何も問題はありません。

ところが、**手元に控えとして書き込まれる名札は1枚だけ**でした。

貼られたURLが古いほうの名札だと、突き合わせは永遠に一致しません。
そして一致しなかったとき、この仕組みが出せる答えは「見つかりません」の一択でした。

## 「無い」と言うのは、実はとても難しい

今回いちばん考えさせられたのはここです。

**「有る」は、1つ見つければ証明できます。**
**「無い」は、全部見たと言えないと証明できません。**

私が作った仕組みは、フォルダ1つにつき名札を1枚しか見ていませんでした。
つまり最初から「全部見る」ことができない作りだったのに、
出てくる答えだけは「存在しません」という言い切りだったわけです。

しかもAIは、その言い切りに理由を付けてくれます。
「同期されていないのでは」「ゴミ箱では」。**どちらも、確かめていない作り話です。**

AIが受け取っていたのは「見つからなかった」という一言だけでした。
理由の欄が空っぽなら、埋めようとして推測が入ります。人間と同じです。

## 直し方は、探す場所を変えることだった

同期アプリは、実はパソコンの中に**自前の目録**を持っています。
クラウドにある全部のファイルとフォルダについて、名札も、どのフォルダの中にあるかも、そこに書いてあります。

名札を1枚ずつ手作業で照合するのをやめて、この目録を引くことにしました。
目録は**名札を全部知っている**ので、何枚あろうと取りこぼしません。

結果は分かりやすいものでした。

- 前のやり方：**9分かけても終わらない**（しかも答えが間違っている）
- 今のやり方：**0.45秒**

目録には、この事務所のパソコンが把握している **54,737件** ぶんの記録が入っていました。
そこから1件を引き当てるのに、実測で1000分の1秒もかかりません。

ついでに、遅さそのものも危ないと気づきました。
時間のかかる探し方は、**途中で力尽きた結果を「無い」と呼んでしまう**ことがあります。
速くしたのは待ち時間のためだけではありません。

## 便利にしたら、覗ける状態になっていた

もう一つ、直したことがあります。

この目録には、**扱っている全部の会社の資料**が載っています。
URLさえ貼れば置き場が分かる、というのは、裏を返せば
「URLを知っている人なら、他の会社の資料の在りかを聞き出せる」ということです。

そこで、割り出した場所が**いまのチャットが扱ってよい会社の資料の中にあるとき**だけ答えるようにしました。
外側なら、場所もフォルダ名も返しません。

このとき気をつけたのは、
**「目録に無い」と「別の会社のものなので扱えない」を、別の言葉で返す**ことです。

どちらも「見つかりません」にまとめると、今度は人間のほうが理由を取り違えます。
今回、私が半日ぶん間違った方向に走ったのと同じことが起きます。

## 学んだこと

**答えが「無い」のときこそ、探し方を疑う。**

「無い」は、それ自体では何も証明していません。
証明しているのは「私の探し方では見つからなかった」ということだけです。

そして、それらしい理由が添えられているときほど気をつけたほうがいい、とも思いました。
理由が付いていると、人は確かめずに納得してしまいます。
私は実際、確かめずに納得して、そのまま報告しました。

いまは「見つからない」の中身を分けて返すようにしています。

- 目録に無い（削除済み、または別のアカウントのもの）
- 見つかったが、別の会社のものなので扱えない
- 見つかって、場所も分かっている

分けて返すようになってから、こちらが取り違えることは無くなりました。
