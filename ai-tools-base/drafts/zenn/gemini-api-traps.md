1文の指示から企画・スライド・音声・動画まで作るパイプラインを組んでいて、
Gemini API で立て続けに4つ踏みました。**どれもエラーメッセージから原因が読めない**
タイプだったので、症状と原因を残しておきます。

## 罠1: SDKが提供終了していた

```python
import google.generativeai as genai   # ← これはもう古い
```

検索して出てくる記事の多くがこの `google-generativeai` を使っていますが、**提供終了**です。
現行は `google-genai`。パッケージ名もインポート名も違います。

```bash
pip install google-genai
```

古い方は当面動いてしまうことがあるので、**動いているうちに気づけない**のが厄介です。
新規に書くなら最初から新SDKにしてください。

## 罠2: モデル名が404を返す

```
404 models/gemini-2.0-flash is not found
```

モデル名を打ち間違えたのかと何度も見直しましたが、**そのモデルが提供終了していた**だけでした。

生成AIのモデルは思っている以上の速度で入れ替わります。**記事に書かれたモデル名をコピーすると、
数ヶ月後には404になる**と考えておいた方がいいです。

対策としては、モデル名を設定ファイル（環境変数）に出して、コード中に直書きしないこと。
差し替えが1箇所で済みます。

## 罠3: JSONを求めると本文が空、または途中で切れる

いちばん時間を溶かしたのがこれです。

**症状**: 構造化データ（JSON）を返させたいのに、返ってくる本文が空。
あるいは途中でぶつ切りになる。エラーは出ない。

**原因**: 新しい世代のモデルは、回答を出す前に**内部の「思考」にも出力トークンを使います。**
出力枠を通常の感覚（1000〜2000程度）で設定していると、**思考の途中で枠を使い切り、
本文に到達しません。**

**直し方**: ①JSON形式であることを明示的に指定する ②出力枠を3倍程度（最低8000）確保する。

```python
config = types.GenerateContentConfig(
    response_mime_type="application/json",   # ①
    max_output_tokens=8000,                  # ②
)
```

**実測: 失敗し続けていたものが、この2点で14.5秒で成功しました。**

「空が返る」を見ると普通はプロンプトを疑いますが、今回は**枠の問題**でした。
出力が空・途中切れのときは、まず `max_output_tokens` を疑ってください。

## 罠4: タイムアウトの単位がミリ秒

未指定だと5分以上帰ってこないことがあります。当然タイムアウトを設定するわけですが、

```python
types.HttpOptions(timeout=30)     # 30秒のつもり → 実際は 0.03秒
types.HttpOptions(timeout=30000)  # ← 正しい。30秒
```

**単位はミリ秒です。** 秒のつもりで小さい値を入れると即座に落ちるので、
「何を設定しても失敗する」という混乱に陥ります。

## おまけ: 生成した動画が再生できない

Gemini とは別ですが、同じパイプラインで踏んだので書いておきます。

書き出し途中の mp4 を開くと `moov atom not found` で再生できません。

**原因**: 多くのエンコーダは**ヘッダ（moov atom）を最後に書きます。** つまり
書き出し中のファイルは常に壊れた状態です。

**直し方**: 一時ファイル名で書き出し、**完了後にリネーム**する。
これで「中途半端なファイルが完成品の名前で存在する」瞬間が無くなります。

```python
tmp = out.with_suffix(".tmp.mp4")
clip.write_videofile(str(tmp))
tmp.rename(out)   # 完成してから正式な名前にする
```

## おまけ2: 音が出ないときはOSを疑う

生成した音声が鳴らず、コードを疑って数十分を溶かしました。

**Mac本体がミュートでした。**

```bash
osascript -e 'get volume settings'
# output muted:true  ← これ
```

笑い話ですが、**「自分のコードより先に、環境を確認する」**のは本当に大事だと思い知りました。
