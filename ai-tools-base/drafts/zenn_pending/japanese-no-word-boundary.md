契約書の特約条項をAIに書かせています。生成された文章に**実在しない法令名**が混じると困るので、
文章から法令名と条番号を拾って、公的なAPIに照合しています。

その「拾う」ところで詰まりました。**日本語には語の区切りが無い**からです。

## 前の語が、くっついてくる

```
重要事項の説明は宅地建物取引業法第35条に定められている
```

ここから法令名を取り出したい。素直に書くとこうなります。

```python
m = re.search(r"(.{2,30}?法)第(\d+)条", text)
m.group(1)   # → "重要事項の説明は宅地建物取引業法"
```

**「重要事項の説明は」までくっついてきます。**

英語なら空白で切れます。日本語では、**どこから法令名が始まるのか**を、文字だけからは決められません。
「は」で切ればいい、と思うかもしれませんが、法令名に「は」が入る可能性を潰せません。

## 切り出すのをやめて、当てにいく

方針を変えました。**切り出すのではなく、候補を作って辞書に当てる**。

```python
def find_law_name(before: str) -> str | None:
    """条番号の手前の文字列から、実在する法令名を見つける"""
    # 末尾から、長さ違いの候補を作る（長い順）
    for n in range(min(30, len(before)), 0, -1):
        cand = before[-n:]
        if egov.exists(cand):        # 法令の一覧に完全一致で当てる
            return cand
    return None
```

- **末尾から取る**（法令名は条番号の直前にある）
- **長い順に試す**（「建物の区分所有等に関する法律」のような長い名前を先に採る）
- **完全一致だけ採る**（部分一致にすると、また前の語がくっつく）

存在しない名前は、当たらないので自然に落ちます。
生成された文章の検証としては、これで十分でした。

## 「2文字の法令名」が、条件から漏れていた

この形にしたあと、**「民法第562条」が1件も拾えない**という不具合が出ました。

候補の長さを `{2,30}` としていたためです。

```python
for n in range(min(30, len(before)), 2, -1):   # ← 2文字が範囲外
```

「民法」は2文字です。「刑法」「商法」も2文字。
**短い名前があることを、条件の側で潰していました。**

下限を下げて解決しましたが、こういう「境界の1」は、
テストデータに短い例を入れていないと一生見つかりません。

## 住所から市区町村を切り出すのも、同じ話

別のアプリで、統計データと物件の所在地を突き合わせていました。

```python
m = re.search(r"(.+?[都道府県])(.+?[市区町村])", address)
```

「大阪府大阪市中央区」から市区町村を取ると、**「大阪市」で止まります**。
`市` に先に当たるからです。実際に必要なのは「大阪市中央区」でした。

結果、**大阪市全体の人口**と、**中央区の物件**を突き合わせていました。

直し方は、切り出しの正規表現を鍛えることではありませんでした。
**統計を提供している側が返す正式名称を使う**ことです。

```python
# 地域名のメタ情報を一緒に取得して、そこに書かれた名称を使う
params = {"metaGetFlg": "Y", ...}
```

こちらで住所を解釈するのをやめて、**向こうの名前をそのまま採る**。
突き合わせるなら、**相手の語彙に合わせるほうが正しい**という話でした。

## おまけ：条で絞れないAPIとの付き合い方

法令APIには、もう1つ癖がありました。**条を指定して取れません**。

```
民法       → 1.7MB（全文）
借地借家法 → 1.4MB（全文）
```

第562条だけ欲しくても、全文が返ってきます。初回の照合に数十秒かかっていました。

こちらはキャッシュで解決しています。

```python
CACHE_DIR = Path(".egov-cache")
CACHE_TTL = 7 * 24 * 3600     # 法令はそう頻繁に変わらない
```

法令は毎日変わるものではないので、期限を長めに取れます。
**変更の頻度に合わせてキャッシュの期限を決める**、というだけの判断です。

## まとめ

- 日本語は**語の区切りが無い**。正規表現で「切り出す」方針には限界がある
- **候補を作って、辞書に当てる**。長い順・完全一致
- 名前の**最短の例**（2文字の法令名）をテストに入れる
- 相手のあるデータは、**相手が返す正式名称に合わせる**
- 絞り込めないAPIは、**変更頻度に応じたキャッシュ**で付き合う

「日本語だから難しい」ではなく、**切り出そうとするから難しい**のだと思っています。
当てにいく形にすると、たいてい素直になります。
