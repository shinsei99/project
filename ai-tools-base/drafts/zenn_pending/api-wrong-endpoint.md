物件の所在地から、用途地域・災害情報・周辺の統計をまとめて調べるツールを作っています。
公的なAPIをいくつも叩くのですが、そこで踏んだ3つを書きます。

## ① 用途地域が、いつも空だった

鍵は有効。HTTPは200。エラーも出ない。**それでも結果がいつも空**でした。

原因は、**似た識別子の別のデータを呼んでいた**ことです。

```
XKT001 … 別の種類のデータ
XKT002 … 用途地域        ← 必要だったのはこちら
```

識別子が1違うだけで、**存在はする**ので、リクエストは成功します。
その地点にそのデータが無ければ、空の結果が正常な応答として返ってきます。

つまり、**「取り違え」と「本当にデータが無い」の区別がつきません**。

対処は、組み込む前の確認手順を決めることでした。

- **必ずデータがあると分かっている地点**（自社ビルの住所など）で試す
- そこで1件も返らなければ、**呼び先が違う**と判断する
- 空が返り続ける状態を、正常として扱わない

「エラーが出ないから動いている」は、ここでも通用しませんでした。

## ② 拡大率を上げると、件数が0件になる

地図のレイヤを取得するAPIで、**同じ地点なのに件数が変わる**ことに気づきました。

```
XKT014 を z14 で取得 → 1件
XKT014 を z15 で取得 → 0件      # 拡大したのに消える
```

拡大率が高いほど、**地物が間引かれる**仕様でした。
細かく見ようとして拡大すると、かえって取りこぼします。

さらに、レイヤによって**受け付ける拡大率の範囲が違います**。
洪水・津波のレイヤは z14〜15 しか受け付けず、範囲外は HTTP 400 が返りました。

いまは、レイヤごとに「使える中でいちばん粗い拡大率」を対応表で持っています。

```python
ZOOM = {
    "XKT002": 14,   # 用途地域
    "XKT014": 14,   # 洪水浸水想定
    ...
}
```

**地図系のAPIは「拡大率＝取得の細かさ」ではない**、というのが教訓でした。

## ③ 単位が二重に付いた

建ぺい率の表示が `80%%` になっていました。

```python
f"{coverage}%"      # coverage が既に "80%" だった
```

APIが返す値に、**すでに単位が付いていました**。
おまけに `"60.0%"` のような表記も混ざります。

```python
def _with_percent(v) -> str:
    """値に % を付ける。すでに付いていれば足さない。60.0% は 60% に揃える"""
    s = str(v).strip()
    if not s:
        return ""
    s = s.rstrip("%")
    try:
        n = float(s)
        s = f"{n:g}"        # 60.0 → 60
    except ValueError:
        pass
    return f"{s}%"
```

小さい話ですが、**外部の値をそのまま表示に回すときは、必ず一度整える**という形にしました。

## ④ おまけ：社内の画面だけ、地図が出ない

Google Maps のストリートビューが、**社内向けの画面でだけ 403** になりました。

既存の鍵に、**公開サイトのドメインだけを許可する制限**が付いていたためです。
社内の画面は `127.0.0.1:8536` のような住所なので、許可の対象外でした。

対処は、**用途を絞った専用の鍵を新しく作る**ことです。

- Maps Embed API **だけ**に制限する
- **ドメインでの制限は付けない**（社内の画面はポートが変わるため）

鍵を1つで使い回すと、こういう場面で「制限を緩める」方向へ動きたくなります。
**用途ごとに鍵を分けて、それぞれ最小の権限にする**ほうが、結局は安全でした。

## まとめ

- **空が返り続けるのは異常**として扱う。データがある地点で必ず確認してから組み込む
- 地図のAPIは、**拡大率で件数が変わる**。レイヤごとに使える範囲を持つ
- 外部の値は、**単位が付いている前提**で整えてから表示する
- 鍵は**用途ごとに分ける**。制限を緩めるより、分けるほうが安い

公的なAPIは、仕様書があっても**実際に叩くまで分からないこと**が多くあります。
「呼べた」ことと「正しく取れた」ことは別で、その差は**期待する件数**でしか測れませんでした。
