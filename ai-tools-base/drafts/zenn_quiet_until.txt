# なぜ止めるか（2026-08-31 夜・★原因が判明したので設定し直した）:
#   Zenn連携は「pushのたびにデプロイ」。このリポジトリは開発で **1日30〜67回** push される。
#   published: true の記事を articles/ に置いたままにしていたため、
#   **その全部が「同じ記事を投稿しようとする試行」**になっていた。
#   「1日1本」のつもりで、実際は **1日50回投稿を試みていた**。
#   Zennの上限は粗製乱造を防ぐ複合ロジックなので、この状態では永久に解けない。
#
#   8/30 にも静止期間を作ったが、**記事を articles/ に置いたままだったので
#   無関係なコミットが投稿を試み続け、「試行ゼロ」になっていなかった**。今回は違う:
#   詰まった記事を待機場所へ引き上げたので、**pushしても投稿は試みない**。
#
#   ＝ ここで初めて「本当に試行ゼロの24時間」が作れる。
#
# 復帰後の動き（zenn-daily.sh を作り替えた）:
#   出す → 公開されなければ **articles/ から引き上げる**（置きっぱなしにしない）。
#   空コミットでの再デプロイの促しは**やめた**（試行を増やすだけだった）。
