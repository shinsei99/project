## 2026-08-29（サブPC）★追記: 動物の種類とレーザー

### 完了したこと
- **動物を6種類にした**（うさぎ・いぬ・くま・とり・いのしし・かめ）。**種類ごとに速さが違う**
  （かめ 3.5〜5.5 m/s 〜 いのしし 15〜19 m/s）。当たり判定・跳ね方・横移動の可否も種類ごと。
  形は `ANIMAL_TYPES` の表から `createCreature(spec)` が組み立てる（耳＝長い/三角/角/なし、
  くちばし・甲羅・翼・脚の本数をパラメータで指定）。**増やすのは表に1行足すだけ**。
- **レーザーを撃つドラゴンを追加**（出現率10%＝`CONFIG.dragon.rate`）。100m以内に入ると
  1.5秒光って溜め、前方140mだけに0.6秒レーザーを出す。溜め中は減速し、地面に橙の予告帯が点滅する。
  当たると「レーザーに撃たれた」でゲームオーバー（死因を衝突と撃墜で書き分けた）。
- 確認用に `?dragon=1`（全部ドラゴンにする）を追加。

### 発生したエラーと解決策
- **予告帯とレーザー本体を同じ赤にしたら、画面で区別がつかなかった**（撮って気づいた）。
  予告＝橙(0xffae00)、本体＝赤白に変えて解決。
- レーザーは円の当たり判定では表せないので、`laserHit(e)` を別に用意してループから見ている
  （`dz < 0` を弾く＝**ドラゴンの後ろは安全**。追い越したあとに背中から撃たれない）。

## 2026-08-29（サブPC）

### 完了したこと
- **新規アプリ「グロウランナー」（`glow-runner`・ゲームカテゴリ）の最小版を作った**。
  `index.html` 1枚・Three.js（CDN・importmap）。光るボールが自動で前進し、左右移動だけで
  向かってくる動物をよける。ステージ制（速度・出現数・出現頻度がステージごとに増加。
  ステージ2以降は横に動く動物が混ざる）、ゲームオーバー／ステージクリア画面、
  HUD（ステージ・距離・進捗バー）まで。PCキーボードとスマホのドラッグ操作の両対応。
- 後で足す予定の**石・コイン**のために、エンティティを `{kind:'hazard'|'pickup', …}` の
  共通の形にした（`kind:'pickup'` の取得処理はすでに通してある＝コインは見た目を作るだけで動く）。
- 検証: `./va.sh` で 1440×900 と 390×844 の両方を目視。**Console エラー0件**・`va.sh check` 指摘0件。
  タイトル／走行中／ゲームオーバー／ステージクリアの4画面を撮って確認した。

### 発生したエラーと解決策
- **新規フォルダが git に入らない** → 直下 `.gitignore` が1行目 `*` で全無視する方式のため。
  `!glow-runner/` と `!glow-runner/**` を追加して解決（`git add --dry-run` で追跡されることを確認）。
- **`git stash` が失敗し、続く `git pull` が `index.lock` で止まった** → 0バイトの `index.lock` が
  残っていた。`pgrep` で git プロセスが動いていないことを確認してから削除し、再実行で解消。
- **`git stash pop` で `.gitignore` が衝突** → upstream 側（cyborg-defense の行）とこちら側
  （glow-runner の行）が同じ位置に足されていたため。両方を残す形で解決。
- **暗すぎて動物が見えず、避けようがなかった**（スクリーンショットで判明） → フォグを薄くし
  （0.016→0.011）、ボールの点光源を 34m→60m に広げ、進行方向を照らすスポットライトを追加、
  動物にも弱い自己発光を入れた。
- **スマホ縦で走路の端が画面外だった** → `PerspectiveCamera` の fov は垂直方向なので、
  縦長では横が削られる。`aspect < 1` のとき fov を 82° に広げた。
