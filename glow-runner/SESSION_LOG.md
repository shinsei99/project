### 発生したエラーと解決策
- **新規フォルダが git に入らない** → 直下 `.gitignore` が1行目 `*` で全無視する方式のため。
  `!glow-runner/` と `!glow-runner/**` を追加して解決（`git add --dry-run` で追跡されることを確認）。
- **`git stash` が失敗し、続く `git pull` が `index.lock` で止まった** → 0バイトの `index.lock` が
  残っていた。`pgrep` で git プロセスが動いていないことを確認してから削除し、再実行で解消。
- **`git stash pop` で `.gitignore` が衝突** → upstream 側（cyborg-defense の行）とこちら側
  （glow-runner の行）が同じ位置に足されていたため。両方を残す形で解決。
- **暗すぎて動物が見えず、避けようがなかった**（スクリーンショットで判明） → フォグを薄くし
  （0.016→0.011）、ボールの点光源を 34m→60m に広げ、進行方向を照らすスポットライトを追加、
  動物にも弱い自己発光を入れた。
- **スマホ縦で走路の端が画面外だった** → `PerspectiveCamera` の fov は垂直方向なので、
  縦長では横が削られる。`aspect < 1` のとき fov を 82° に広げた。
