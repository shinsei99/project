# グロウランナー（glow-runner）

暗闇の走路を「光るボール」で駆け抜け、向かってくる動物をよけてゴールを目指す 3D ランゲーム。
**`index.html` 1枚で完結**（ビルド不要・依存は CDN の Three.js だけ）。ダブルクリックで開ける。

## 動かし方

```bash
# そのまま開いてもよいが、確認は HTTP 経由が確実（file:// でも動く）
cd ~/glow-runner && python3 -m http.server 8899 --bind 127.0.0.1
# → http://127.0.0.1:8899/index.html
```

- 操作: **PC** ← → / A D キー、**スマホ** 画面を指でなぞる（指の位置へ横移動）
- 開発用の URL パラメータ: `?stage=3`（開始ステージ）/ `?goal=70`（ゴール距離の上書き）
  例: `http://127.0.0.1:8899/index.html?stage=3&goal=70` … 横に動く動物とクリア画面をすぐ確認できる

## ファイルの構成（`index.html` 1枚の中の並び順）

| # | 節 | 役割 |
|---|---|---|
| 1 | `CONFIG` | 走路の幅・ボール・カメラ・**ステージごとの難易度カーブ**をここに集約。数値の調整はここだけ見る |
| 2 | `state` / `stageParams()` | 進行状態と、ステージ番号 n から「速度・ゴール距離・出現間隔・同時出現数・横移動の割合」を出す関数 |
| 3 | シーン | 暗い背景＋指数フォグ、走路タイル（8枚を使い回して無限に見せる）、光るボール、ゴールゲート |
| 4 | ファクトリ | `createAnimal()` … 箱と円錐の組み合わせで動物を作る。**ここを差し替えれば見た目だけ変えられる** |
| 5 | エンティティ管理 | `entities[]` に `{kind, mesh, radius, update()}` を積むだけ。`kind:'hazard'`＝衝突死／`kind:'pickup'`＝取得 |
| 6 | 入力 | キーボード（押しっぱなしで移動）とポインタ（ドラッグ追従）。どちらも `state.targetX` を動かすだけ |
| 7 | UI | HUD（ステージ・距離・進捗バー）とオーバーレイ（タイトル／クリア／ゲームオーバー） |
| 8 | 進行 | `startStage()` / `stageClear()` / `gameOver()` |
| 9 | ループ | 前進 → 入力 → 出現 → エンティティ更新と当たり判定 → タイル使い回し → カメラ追従 |

## あとから足すとき

- **石などの障害物**: 4節に `createRock()` を書き、`entities.push({kind:'hazard', …})` で積むだけ。
  当たり判定・消滅・出現の処理は種類を問わず共通なので、ループ側は触らない
- **コイン**: `kind:'pickup'` を付ければ**当たったときに `state.coins++` して消える処理はもう通してある**。
  残るのは HUD への表示だけ
- 見た目の差し替え（モデル読み込みなど）も `createAnimal()` の中だけで閉じる

## 調べた事実・つまずいた所

- **Three.js は importmap ＋ ES モジュールで読む**。UMD の `three.min.js` は r160 以降 配布されていない。
  CDN が落ちるとモジュールは何も言わずに止まるので、**8秒経っても起動していなければ**
  「読み込めませんでした」を出すようにしてある（白画面で終わらせない）。
- **暗くしすぎると避けられない**。最初 `FogExp2(0.016)` ＋ ボールの光 34m では、動物が見えた時には
  もう目の前だった（実測。スクリーンショットで判明）。フォグを 0.011 に薄め、ボールの点光源を 60m へ広げ、
  さらに**進行方向を照らすスポットライト**を足し、動物自体も弱く自己発光させて解決した。
- **縦画面では横の視野が足りない**。`PerspectiveCamera` の fov は**垂直方向**なので、縦長の画面では
  横が削られて走路の端が見えない。`aspect < 1` のとき fov を 62°→82° に広げている（`fitCamera()`）。
- `favicon.ico` の 404 も Console のエラーになる。data URI の SVG を `<link rel="icon">` に入れて0件にした。
