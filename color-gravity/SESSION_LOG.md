### 発生したエラーと解決策

- **症状**: `xcodebuild archive` が `Signing for "App" requires a development team`
  → **原因**: `npx cap add ios` が作る pbxproj に `DEVELOPMENT_TEAM` が無い
  → **直し方**: `DEVELOPMENT_TEAM = 773DPMVW7Q;` と `CODE_SIGN_STYLE = Automatic;` を2か所に追加。
    **`ios/` は git に入らないので、別PCで作り直したら再度必要**（`RELEASE.md` に明記）

- **症状**: `xcodebuild -exportArchive` が `No Accounts` / `No signing certificate "iOS Distribution" found`
  → **原因**: このMacの xcodebuild に Apple ID が入っていない（`security find-identity` にも配布用は出ない）
  → **直し方**: **API キーを渡す**（`-authenticationKeyPath ~/.appstore/AuthKey_35U53KWY5J.p8` ほか）。
    デジタル書斎で確立した手順と同じ

- **症状**: `altool --validate-app` が
  `Cannot determine the Apple ID from Bundle ID 'com.shinsei99.colorgravity'`
  → **原因**: **App Store Connect に App 記録がまだ無い**。
    **App Store Connect API には新規App作成のエンドポイントが無い**ので、これは画面での作業
  → **対応**: ここで止めて、オーナーに記録の作成を依頼（`RELEASE.md` の「★人にしかできないこと」）

- **症状**: アイコンの惑星が白くぼやけ、背景にもう1つ大きな星があるように見えた
  → **原因**: 球のグラデーションをキャンバスへ直に描いたので、円からはみ出した分が背景に広がった
  → **直し方**: 別レイヤーに描いて**円のマスクで貼る**（`sphere()`）

- **症状**: 撮影した `flight` の絵で星が盤外に出ていた
  → **原因**: `flyTo(150)` は進みすぎ（5面の正解は336歩で、150歩では左端の外）
  → **直し方**: 物理を実際に走らせて座標を出し、**3つのゲートを抜けた直後の50歩**に変更

### 発生したエラーと解決策

- **症状**: 鏡で跳ねたときに音を鳴らそうとして `stepSim` の反射部分を `return 'bounce'` にした
  → **原因**: 早期に戻ると**同じフレームのゲート判定と結晶判定が飛ばされ、軌道が変わる**。
    鏡のある 5・7・13・16・19 面の `sol`（正解の発射ベクトル）が的を外す
  → **直し方**: 戻り値は増やさず、`s.bounced` / `s.lastGate` という**印だけ**を付ける。
    `stepSim` はこの2つを読まないので軌道は1ミリも変わらない。
    **`tools/verify_solutions.py` を先に作っておいたから気づけた**（目視では絶対に分からない。
    それらしい弧を描いて外れるだけなので「そういう面」に見える）

- **症状**: `./va.sh` で撮ったスクリーンショットが**ひよこ防衛軍**になっていた
  → **原因**: `va.sh` のブラウザは**1台に1つの共有インスタンス**。別セッションが同時に使っていた
  → **直し方**: 取り合わず、Playwright で**自前のブラウザ**を立てて撮った
    （`agent-platform/.venv/bin/python` に playwright が入っている）

- **症状**: Console に 404 が1件出続ける
  → **原因**: favicon が無い
  → **直し方**: SVG を data URI で `<link rel="icon">` に直書き（ファイルを増やさない）。
    本物のエラーが埋もれるので、放置しないほうがよい

- **症状（見た目）**: 砲台を下へ引くと星が盤面の外へはみ出す（砲台が y=558／盤面 600 のため）
  → **直し方**: 引いた星の**表示位置だけ**を盤内にクランプ（発射ベクトルは触っていない）
