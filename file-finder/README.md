# 横断ファイル検索ブラウザ (file-finder)

社内共有ドライブの棚卸しExcel（`全ファイル一覧.xlsx`）を読み込み、**11,000件超のファイルをフォルダ階層を辿らず横断で即検索**するツール。

## できること
- ファイル名・フォルダパス・推定物件名を対象に **スペース区切りAND検索**
- **カテゴリ / 拡張子 / 更新日範囲** で絞り込み、更新日・サイズ・名前で並び替え
- 行クリックで詳細パネル → **フルパスをコピー**して共有ドライブで開く
- ヒット件数・合計容量を表示、**検索結果をCSV書き出し**
- サイドバーから最新の棚卸しExcelに差し替え可能

## データ
- `data/全ファイル一覧.xlsx`（5カテゴリ：営業・募集／管理業務／業者・設備管理／経理・請求書／社内・総務）
- 列：種別・フルパス・名前・親フォルダ・階層・拡張子・サイズ・サイズ(bytes)・更新日時
- ※ ファイルの「中身」ではなくメタデータのみ
- ⚠️ **このExcelは物件名・取引先名を含むため、公開リポジトリにはコミットしない**（`.gitignore`で `data/` を除外）。
- 実際のフルパスは各カテゴリ名（トップ階層フォルダ）を先頭に付けて表示・コピーされる（例：`営業・募集/物件資料/…`）。

## 別PCでの引き継ぎ（アップロード方式）
1. `git pull` でコードを取得（`data/` のExcelはgitに含まれない）
2. `python3 -m streamlit run app.py --server.port 8520` で起動
3. データが無いので画面上部のアップローダーが自動で開く → **全ファイル一覧.xlsx** を選択すれば検索開始
   - 常設したい場合は Excを `file-finder/data/全ファイル一覧.xlsx` に置けば、次回から自動読み込み（アップロード不要）

## 起動
```bash
cd file-finder
pip install -r requirements.txt
python3 -m streamlit run app.py --server.port 8520
```
→ http://localhost:8520

## ★ 棚卸しExcelの作り直し（2026-08-30 追加）

**毎週日曜 5:00 に自動で走る**（`com.shinsei.file-finder-inventory` / 2026-08-30 追加）。
作り直し → 共有フォルダの置き換え → 8520の読み直し → 控えの世代管理 まで1本で終わる。

```bash
./run_inventory_weekly.sh          # 週次と同じことを手で流す
DRY=1 ./run_inventory_weekly.sh    # 下見だけ（共有フォルダは触らない）

# 中の道具を直接使う場合
python3 build_inventory.py            # 下見（data/ にだけ書く）
python3 build_inventory.py --publish  # 共有フォルダの実物も置き換える
```

plist は `_launchd/com.shinsei.file-finder-inventory.plist`。入れ直しは
`launchctl bootout` → `bootstrap`（**引数を変えたら `kickstart -k` では反映されない**）。

### 週次ジョブが守っていること

- **失敗したら 8520 を触らない**（古いままの方が安全。中途半端に読ませない）
- **アプリの読み直しまでやる**。ここを忘れると「Excelは新しいのに画面は古い」になり、
  しかも誰も気づけない
- **控えは8本（約2か月）まで**。超えたら古いものから消す。消す件数をログに出す
- **同じ日に2回流しても、前に取った控えを上書きしない**（上書きすると「置き換える前の版」
  ではなく「さっき自分が置いた版」が残り、戻せなくなる）
- `/bin/bash` 経由・`PATH` を明示（launchd の2大罠。README下部参照）

**この道具ができるまで、作る側の仕組みは存在しなかった。**
オーナーの認識は「定期的に自動で作り直してもらっている」だったが、
2026-08-30 に列名（`親フォルダ`）とファイル名で全体を探して**0件**。人の手か外部の手だった。
実際、実物は **2026-07-22 で更新が止まっていた**（1ヶ月以上）。

### 出力の形（既存Excelに合わせてある）

- 共有フォルダの**トップ階層のフォルダごとに1シート**
- 列: 種別 / フルパス / 名前 / 親フォルダ / 階層 / 拡張子 / サイズ / サイズ(bytes) / 更新日時
- フルパス・親フォルダは**そのシートから見た相対パス**
- サイズは2進換算で `9 B` / `45.5 KB` / `303.0 MB`
- 隠しファイル（`.DS_Store`）は入れない

### はまり所

- **macOSのファイル名は分解形(NFD)で返る**（「ブ」が「フ」+濁点）。そのまま書くと
  旧Excel（NFC）とシート名すら一致しない。**NFCに正規化してから書く**。
  なお `app.py` は検索時に NFKC で両側を正規化するので、検索自体は壊れない
- **`--publish` は全社員が見るファイルを置き換える。** 先に下見で件数を確かめること
- 置き換え前の控えは**共有フォルダの `_アーカイブ` へ入れる**（直下に置くと
  社員が「どっちを開くのか」と迷う）
