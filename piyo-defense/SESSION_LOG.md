あわせて直したもの:

- **タイトル画面が独自の暗い空（下端 `rgb(4,3,14)`）と平らな緑の長方形**を持っていて、
  遊び始めると絵が変わってしまっていた。`drawBg`/`drawGround` に統一した
- HUD右上の「撃破:0 HS:0」が9pxの灰色でコインのアイコンと重なっていた → 枠を1つ置いて上下に分けた
- タイトルのスコアパネルが2行を11px間隔で詰めていた（重なり） → 行間15pxに広げた
- 「全20ステージ × 5Wave構成」が村の絵と重なって読めない → 下敷きを敷いた
- **favicon.ico の404が唯一のConsoleエラーだった** → ひよこのSVGを data URI で埋め込んで0件に

**書体は Kosugi Maru → Zen Maru Gothic に変えた。** 理由は2つ。
Kosugi Maru はウェイトが400しかなく、タイトルの `bold 46px` が**ブラウザの合成太字**
（にじむ）だった。Zen Maru Gothic には 500/900 の実ウェイトがある。もう1つは
にゃんこアイスと同じ書体になり、2本の見た目が揃うこと。どちらも SIL OFL 1.1 で再配布可。

### 発生したエラーと解決策

- **症状**: `js/render.js` を直しても画面が変わらない。`curl` ではサーバは新しい内容を返す
  → **原因**: **ブラウザのディスクキャッシュ**。`location.reload(true)` は現行Chromeでは無視される。
    `?v=` を付けても index.html しか更新されず、`js/*.js` は古いまま読まれる
  → **直し方**: `Cache-Control: no-store` を返す小さなサーバで開くか、**ブラウザを開き直す**。
    「直したのに変わらない」ときは、まずコードではなくキャッシュを疑う（30分溶かした）

- **症状**: 書体を同梱に切り替えたのに当たらない
  → **原因**: **canvas の `ctx.font` に指定しただけでは Web フォントは読み込まれない。**
    DOMに1文字も無いので `@font-face` が「使われていない」と判定される
  → **直し方**: `game.js` の冒頭で `document.fonts.load()` を明示的に呼ぶ。
    描画は毎フレームやり直しているので、読み終わった時点から自動で切り替わる

- **症状**: 図鑑の未発見枠（影絵）なのに、緑に光ったり鎧が見えたりして種類が分かってしまう
  → **原因**: `drawCrow` の種類別の演出（オーラ・シールド・鎧・透明化）が影絵にも適用されていた
  → **直し方**: `e.silhouette` のときは演出ブロックごと飛ばす。透明化する種類
    （ゴースト/ステルス/ファントム）のアルファ操作も外す。**消えていると集める対象に見えない**

- **症状**: ゲームオーバー画面で、地球の隣に灰色の塊が出る
  → **原因**: 月の位置（`_W*0.79, 214`）に、この画面は地球（`_W/2, 228`）を描いていた。
    さらに `rgba(0,0,0,0.80)` の幕で月が灰色に沈んでいた
  → **直し方**: `drawBg(frame, stage, hideMoon)` の第3引数を足し、ゲームオーバーだけ月を消す
