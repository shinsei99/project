## 説明（4000字以内・絵文字なし）

```
ひよこの村に、カラスの大群が攻めてきます。
あなたが動かすのは、たった1羽のひよこ。
夜空を見上げながら、村と地球を守り抜いてください。

【指1本、左右に動かすだけ】
ひよこは左・中央・右の3つのレーンを行き来します。
画面下のボタンを押すか、画面を左右になぞるだけ。
攻撃は自動なので、あなたは「どこに立つか」だけを考えます。
片手で、電車の中でも遊べます。

【空に浮かぶ雲がタワーの土台】
夜空にふわふわ浮かぶ雲をタップすると、そこにタワーが建ちます。
ノーマル、ラピッド、スナイパー、サポートの4種類。
射程も、威力も、連射の速さも違います。
同じ雲をもう一度タップすればレベルアップ。
どこに何を建てるかで、勝ち方が変わります。

【3羽の仲間】
軍師、ナース、バリア。画面の下にいる仲間はタップで動きます。
使いどころを間違えると、次に使えるまで待たされます。
「今出すか、もう少し我慢するか」がこのゲームの山場です。

【にわトリに変身する】
カラスを倒すとゲージがたまります。
いっぱいになるとひよこがにわトリに変身し、攻撃力が跳ね上がります。
さらに条件を満たせば、エンジェル形態も。

【全20ステージ、ボスは全部ちがう】
ステージが進むごとに夜空の色が変わっていきます。
藍色の夜明け前から、紫の夜、赤い異変の空、そして深い宇宙へ。
5ウェーブ目には必ずボスが出ます。20ステージ、20体、すべて別の姿と攻め方です。

【23種類の敵図鑑】
倒した敵は図鑑に登録されます。
まだ倒していない敵は影絵で表示されるので、
「あと何がいるのか」を見ながら集められます。

【負けても強くなる】
集めたコインで、初期HP、攻撃力、移動速度などを恒久的に強化できます。
強化はゲームオーバー後も消えません。
届かなかったステージに、少しずつ手が届くようになります。

【広告なし、課金なし、通信なし】
広告は1つも出ません。アプリ内課金もありません。
インターネットにも接続しないので、機内モードでも最後まで遊べます。
集めた記録はすべて端末の中だけに保存され、外へ送られることはありません。

【こんな方に】
・短い時間でひと勝負したい方
・片手で遊べるゲームを探している方
・広告で中断されるのが苦手な方
・タワーディフェンスは好きだが、置くだけでは物足りない方

夜の村に、明かりがともっています。
守るものが見えていると、少しだけ強くなれます。
```

【アプリの概要】
3レーンを移動しながらタワーを建てて敵を迎え撃つ、単一プレイヤーのタワーディフェンスです。

https://github.com/shinsei99/project/tree/main/piyo-defense

1. 据置き型のタワーディフェンスと違い、プレイヤーが操作するキャラクター（ひよこ）が
   3レーンを移動し、自身も攻撃と被弾を行います。

--- English ---
A single-player lane-based tower defense game. Fully offline.
No login, no account, no in-app purchase, no ads, no data collection.

How to test:
1. Launch and tap START
2. Move the chick with the left/right buttons at the bottom, or swipe horizontally
3. Tap a floating cloud platform in the sky to build a tower
4. Tap the three circles at the bottom to use skills
5. A boss appears on wave 5 of each stage

Regarding Guideline 4.3: this app does not use any template or app-generation service.
All artwork is drawn in code with the Canvas API; the only image assets are the app icon
and the launch screen. Source code is public:
https://github.com/shinsei99/project/tree/main/piyo-defense

Differences from similar apps: the player controls a character that moves between three
lanes and both attacks and takes damage, rather than only placing static towers.
