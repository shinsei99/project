### 2026-08-21（その3）で追加した仕様 — 住所の扱いと複数書式

- **`所在地`（住居表示）と `登記所在`（謄本の所在）は別項目**。混ぜない。
  謄本に住居表示は載っていないので、住居表示の出どころは**マイソクか人の入力だけ**
- **住所の入力欄は2つ**（町名まで／丁目・番・号）。日本郵便で確認できるのは**町名まで**
  （丁目すら持っていない。実測で確認済み）
- **入力の順番はマイソク → 謄本 → 住所**。分かる部分は自動で出し、足りない分だけ人が打つ
- **書式は複数選べる**（＋で1本でも6本でも。分類をまたいでも消えない。2本以上はZIP）
- **取引種別（売買/賃貸）で書式を絞る**。売買 11分類139本 / 賃貸 9分類87本。
  種別に関係ない書類（犯収法・取引台帳など）は「共通」で両方に出す
- **分類の下の小分類（フォルダ）を出す**。既定は本体（契約書なら契約書そのもの）
- **同じ小分類の中は1つだけ選ぶ**。増やすときは分類を選び直して「＋」で足す
- **基本セットが先、追加書類は畳む**。セットは 3種別（土地・建物／区分所有／土地のみ）
  × 売主の立場（一般売主／宅建業者売主／消費者契約用）。**既定は一般売主**（媒介が大半）
- **マイソクは鵜呑みにしない**。所在地・最寄駅・種目を謄本と公的データに突き合わせ、
  🟡 があれば「そのまま書類に載せない」と警告する
- **謄本は確定として扱う**。見るのは発行日だけ（30日以内=🟢／90日超=🟡取り直し）
- マイソク解析は**この重説アプリ側に持つ**（`maisoku-converter` には触らない。役割が別のため。
  ただし claude CLI の場所解決・向き補正は共有 `registry_parser.py` を使う）

#### 元の調査メモ（2026-08-21）

- **土地の売買・交換用には「抵当権」欄が無い**。様式が違い、「所有権にかかる権利に関する

  **土地のものでも建物欄に入る**。土地と建物で分けて持つべき（`抵当権` を

### 目的

区分所有では**専有部分の謄本が本体（居宅）と車庫で別々に発行される**。実例:
OAPレジデンスタワー307号（本体 家屋番号 1-20-1-307 / 車庫 1-20-1-61「車庫３４１－３４２」）。
いまのアプリは建物謄本を**1枚しか受け取れず**、共有パーサも複数枚を
`_deep_merge`（後勝ち）で1件に潰すため、**車庫の値が本体を上書きして気付かないまま
誤った専有面積・家屋番号が書面に入る**恐れがある（順番依存＝再現しにくい事故）。

### 実装内容

1. `registry_parser.parse_registry`: PDFごとの結果を潰さず `建物一覧` として残す。
   **主たる建物（車庫・駐車場・物置以外）を選んで**既存キー（`建物`/`マンション`）に入れ、
   残りを `附属建物一覧` に置く。**既存キーの意味は変えない**ので 8517 側は無改修で
   「順番依存で車庫に上書きされる」問題だけが消える。
2. `services/registry_service.py`: `附属建物` を PropertyData に足して画面に出す。
3. `app.py`: 建物・土地の謄本アップロードを**複数可**にする（共有パーサの上限は5枚）。
4. 書式への流し込み方は**オーナー確認待ち**（下記）。

### オーナー確認の結果（2026-08-24・確認済み）

**「2015年の実案件と同じ書き方にする」で決裁。** 実装は次のとおり:

- 家屋番号・種類は **`①本体　②車庫` と連記**する。連記した文字列は
  `家屋番号記載` / `種類記載` という**別のキー**に持ち、書式へはそちらを流す
  （素の `家屋番号` / `種類` は本体の値のまま。クロスチェックの突き合わせが壊れないため）
- **床面積は本体のみ**（連記しない）
- 車庫の敷地権割合・サイズは**自動では書き込まない**。画面に「附属建物も読み取りました」と
  出すところまでにして、備考欄への転記は人がやる（備考欄は書式のあちこちにあり、
  機械で当てると誤爆するため。**ここは手作業が残る**）

### 確認の根拠にした実物

2015年の実案件（`重説-ＯＡＰ307号.xlsx`）では人が次のように書いていた:

- 家屋番号 H112 … `①天満橋一丁目１番20の1の307　②天満橋一丁目１番20の1の18` と**連記**
  （※`の18` は謄本の `の61` と食い違う。当時の誤記と思われる）
- 建物の番号 AC112 … `①307号　②車庫61号`
- 種類 H114 … `①☑居宅・□店舗・□事務所・②☑車庫`（**両方にチェック**）
- 床面積 H118 … **本体のみ**（登記記録 72.59 ㎡）。車庫の 16.38 ㎡ は書いていない。付属建物は `☑無`
- 車庫の敷地権割合・サイズは、下の備考行に文章で（`分譲車庫 61号の敷地権の割合…1000分の824`）

→ **この書き方を機械の既定にしてよいか**（特に「床面積は本体のみ」で合っているか）を確認する。

- [ ] **区分建物でAIが `建物.家屋番号` と `建物.種類` を落とすことがある**（出力ゆれ）。

      車庫・駐車場だけ補っている。それ以外の種類は補わず空のままにしてある
