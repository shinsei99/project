# サイボーグ防衛軍（cyborg-defense）

上から降りてくる敵ロボの群れを、**左右の位置取りだけ**で迎撃する防衛シューティング。
ゲーム系・HTML単体（ビルド不要）。**Web版は GitHub Pages、iOS版は Capacitor で同じ `www/` を包む。**

```
open www/index.html                                    # そのまま開ける
cd www && python3 -m http.server 8907 --bind 127.0.0.1 # ★書体と音を確かめるときは HTTP で開くこと
```

| フォルダ | 中身 |
|---|---|
| `www/` | **ゲーム本体**（`index.html` 1枚＋書体）。Web版もiOS版もここが正 |
| `ios/` | Capacitor が作る Xcode プロジェクト（**git に入れない**。作り直せる） |
| `icon-src/` | アイコンと起動画面の生成スクリプト |
| `screenshots/` | App Store 用スクショの撮影一式 |
| `store-text.md` / `RELEASE.md` | ストア文言と、提出の手順・状態 |

**file:// で開くと書体が当たらないことがある**（woff2 の読み込みがブラウザによって
クロスオリジン扱いになる）。見た目の確認は必ず HTTP 経由で。

## 遊びの仕組み（数値は `www/index.html` の1か所にまとまっている）

| 要素 | 中身 |
|---|---|
| 部隊 | 左右ドラッグ（PCは ← → ）で移動。射撃は自動。1列6人まで、最大18人 |
| 複製ゲート | 3択。`×2 ×3 +N ÷2 -N` を毎回シャッフル。**×2 が常に最善にならないよう罠を混ぜてある** |
| 感電バリア | 1レーンに降下。当たると部隊が4人減る＝位置取りを強制する装置 |
| シールドボス（装甲隔壁） | 45秒ごと。壊すと +30◈。防衛ラインまで降りられると HP -28 |
| 強化 | 基本兵士（最大6）／連射／威力。◈ は撃破とコンボで貯まる |
| コンボ | 連続撃破。5連ごとにボーナス。被弾・突破で途切れる |

**横移動は `W*0.16` の帯に制限してある**（`margin()`）。狭いほうが択が効くため。
画面の両脇には防壁を描いてあり、**この制限が絵として説明されている**状態にしてある。

## 見た目（2026-08-28に作り替えた）

黒地＋薄いグリッドだけだった画面を、4層に作り替えた。

1. **空**（星・環のある月）／2. **遠景の街**（2列。奥は暗く小さい）／
3. **通路の床**（消失点へ収束＋手前ほど速くスクロール）／4. **自軍拠点**（防衛ラインより手前）

- 背景の動かない部分は**1枚のオフスクリーンに焼いてから貼る**（`buildBackdrop()`）。
  毎フレーム描き直すと、街の窓とグラデーションだけで処理が重くなる
- **遠近線は薄く引くこと**。濃く引くと床ではなく「光のビーム」に見える（一度やって直した）
- 地平線は `H*0.22`。低くすると敵の大半が空の上を歩いているように見える

## 書体

`assets/fonts/` に **Orbitron**（数字・英字）と **Zen Kaku Gothic New**（日本語）を
使う文字だけに絞って同梱（4ファイル・計77KB）。どちらも SIL OFL＝商用可・再配布可。

**画面の文字を変えたら `python3 tools/fetch-font.py` を流し直す。**
忘れると増やした文字が □（豆腐）になる。`× ÷ → ◈` は Orbitron に無いので、
CSSのフォント指定（Orbitron → ZenKaku の順）で日本語側が受け皿になっている。

## 音

**音のファイルは同梱していない。すべて WebAudio の合成音**（効果音11種＋BGMループ）。
オン/オフは画面右上のボタン、記憶は `localStorage`（`cyborg_sound`）。

- iOS は操作するまで音を出せないので、最初のタップ・キー操作・ボタンで `initAudio()`
- 射撃音は毎秒2〜5回鳴るため、**極端に短く・小さく**してある
- BGM はイ短調ペンタトニック。**ウェーブ3以降は裏拍のハイハットが増える**
- 素材に差し替えるときは `assets/audio/` に置いて `USE_FILES = true`。
  **商用可かつ再配布可のものだけ**（このリポジトリは public・GitHub Pages で配信）

## 公開

### Web版（GitHub Pages）

`.github/workflows/deploy.yml` の `DEPLOY_FOLDERS` に **`cyborg-defense:www`** を入れてある
＝ **main に push すると gh-pages が更新される**。手で置きに行かないこと。
公開先: https://shinsei99.github.io/project/cyborg-defense/
（`support.html` / `privacy.html` も同じ場所に出る＝App Store の必須URL）

### iOS版（App Store）

**2026-08-28 に提出直前まで用意した。** ipa の書き出しまで終わっていて、
残りは **App Store Connect で App 記録を作ること**（APIでは作れない）。
手順と現在の状態は **`RELEASE.md`** にすべて書いてある。

- `com.daikyo.cyborgdefense` / 1.0 (build 1) / iPhone・iPad 対応・縦持ち固定
- **広告なし・課金なし・通信なし**（ipa の Frameworks は Capacitor と Cordova の2つだけ）
- MinimumOSVersion **15.0**（2027年春からの必須要件を満たしている）
