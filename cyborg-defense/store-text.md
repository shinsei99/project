## 先に人がやること（1回だけ・App Store Connect の画面）

作ったら `python3 push-metadata.py --apply` と `python3 push-screenshots.py …` が通るようになる。

## なぜこの文言なのか（先に読む）

**提出前に App Store を実測した**（2026-08-28・iTunes Search API）。KeyTag が
Guideline 4.3(a)（スパム＝他の開発者のアプリと似ている）で差し戻された教訓による。

| 調べたこと | 結果 |
|---|---|
| `サイボーグ防衛軍` の完全一致（jp / us） | **なし**（名前は空いている） |
| `サイボーグ・ディフェンス` / `Cyborg Defense` の完全一致 | **なし** |
| 近い遊び（ゲートで人数が増減する群衆ゲーム） | **量産アプリが多い棚**。`カウントマスターズ`（Freeplay）／`Count Master: Stickman 3D Race`／`Crowd Rush: Army Runner`／`Army Runner 3D`／`ふえる軍団！ゲートアーミー`／`Tall Man Run` など |
| 近い名前の防衛ゲーム | `SpaceXYZ: Idle Tower Defense` ほかタワーディフェンス多数（**遊びは別物**） |

**つまりゲート系は 4.3(a) を踏みやすい棚。** ただし量産群は全て**「走って進む」**ゲームで、
本作は**走らない**。決められた防衛ラインの手前で左右に位置取りし、上から降りてくる敵を
迎撃し続ける。ゲートは「進む道の分岐」ではなく、**戦力を増減させる増援装置**として降りてくる。

| ✅ 前に出す | なぜ効くか |
|---|---|
| **走らない。守る。**（ランナーではなく防衛戦） | 量産ゲート系との最大の違い。1行目で言い切る |
| **ゲートに「くぐると何人になるか」が出る** | 運任せではなく**読み合い**になる。量産群には無い |
| **広告が出ない・課金がない・通信もしない** | 量産群はほぼ全て広告収益型。最も分かりやすい違い |
| **絵は外部素材ゼロ。全部その場で描いている**（canvas の手描きベクター） | 量産群は同じ素材集の使い回しが多い |
| **感電バリア・重装ブルート・装甲隔壁** の3種の脅威 | 「ゲートをくぐるだけ」ではない |

❌ 名前や説明の主役を「群衆ゲーム」「ランナー」にしない（量産群の棚に自分から入る）。

## 説明（4000字以内）

※ **App Store の説明に絵文字は入れられない**（にゃんこアイスで HTTP 409 `INVALID_CHARACTERS`／`Description can't contain 🍦`）。以下は絵文字なし。

```
指1本、左右にドラッグするだけ。射撃は自動です。
上から降りてくる敵ロボの群れを、防衛ラインの手前で迎え撃ってください。

■ 走らない防衛戦
コースを走り抜けるゲームではありません。守る線は決まっています。
どこに立つか、それだけで戦況が変わります。

■ 複製ゲートは3択
降りてくるゲートは毎回シャッフルされた3つの枠。
×2 や ×3 は強力ですが、その両隣には ÷2 や -N の罠が待っています。
枠には「くぐると何人になるか」が表示されるので、運任せではなく読み合いになります。

■ 3種類の脅威
・感電バリア … よけないと部隊が減ります
・重装ブルート … 硬く、突破されると部隊を食われます
・装甲隔壁 … 壊すとボーナス。放っておくと防衛ラインに激突します

■ 強化はいつでも
撃破で貯まるコインで、基本兵士・連射・威力をその場で強化できます。
連続撃破のコンボでボーナスも入ります。

■ 安心して遊べます
・広告は出ません
・アプリ内課金はありません
・インターネットに接続しません（機内モードでも遊べます）
・アカウント登録も、個人情報の入力もありません
・記録（ベストスコア）は端末の中だけに保存します

■ こんな方に
・片手で、短い時間だけ遊びたい
・広告で中断されるゲームに疲れた
・ハイスコアを1点ずつ伸ばすのが好き

絵はすべてその場で描いています（外部の画像素材は使っていません）。
書体は SIL Open Font License の Orbitron と Zen Kaku Gothic New を使用しています。
```
