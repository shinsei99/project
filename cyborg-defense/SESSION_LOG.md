### 発生したエラーと解決策

- **症状**: アイコンが**全面真っ黒**で出てきた
  → **原因**: 光を `Image.blend(img, 黒い光レイヤ, 0.9)` で足していた。blend は**黒への線形補間**なので、
    足すどころか画像を黒く潰す
  → **直し方**: 光は `ImageChops.add`（加算）、実体は `ImageDraw` で直接描く。`make_icon.py` の冒頭に明記

- **症状**: PIL の `arc` / `rounded_rectangle` が `x1 must be greater than or equal to x0` で落ちる
  → **原因**: 左右対称に描くとき、左側で x が逆転していた
  → **直し方**: 計算してから `min/max` で並べ替える

- **症状**: 最初のスクリーンショットが**真っ黒**
  → **原因**: 起動から6秒で撮っていた。**WebView の描画が間に合っていない**（起動画面のまま）
  → **直し方**: 12秒待つ

- **症状**: スクショの構図が崩れる（ゲートが下まで流れる・WAVE が 1 に戻る）
  → **原因**: 起動直後に構図を作っていたので、撮影までの十数秒でゲームが進んでいた。
    ウェーブ数は `update()` が `G.t` から計算し直すので、止めないと戻る
  → **直し方**: **撮る直前（9.2秒）に構図を作り、`syncHUD()` してから `G.running=false` で止める**。
    `draw()` は動き続けるので絵は出る

- **症状**: `xcrun altool --validate-app` が
  `Cannot determine the Apple ID from Bundle ID 'com.daikyo.cyborgdefense'` で失敗
  → **原因**: **App Store Connect に App 記録が無い**。`POST /v1/apps` を実測すると
    `The resource 'apps' does not allow 'CREATE'`＝**APIでは作れない**
  → **直し方**: オーナーが画面で作る（`RELEASE.md` に入れる値を書いた）

## 2026-08-28（メインPC）— 見た目・書体・音を作り替えた

オーナー依頼「にゃんこアイスを魅力的にしたときみたいに、もっと魅力的にしたい」。
**遊びの数値（HP・部隊数・敵の出現ペース・強化コスト・ゲートの中身）は1つも変えていない。**
変えたのは、見せ方・書体・音・手触りだけ。

### 完了したこと

| | 内容 |

| **背景（4層）** | 黒地＋薄いグリッドだけだった画面を、空（星・環のある月）／遠景の街2列／消失点へ収束する通路の床／自軍拠点（防衛ラインより手前）に作り替えた。動かない部分は**1枚のオフスクリーンに焼いてから貼る**（`buildBackdrop()`）。街の窓とグラデーションを毎フレーム描くと重い |
| **両脇の防壁** | 装飾ではなく、**横移動が `W*0.16` の帯に制限されている理由を画面で示す**ために描いた。以前は「なぜか端まで行けない」状態だった |

| ファビコン | data URI の SVG に。外部ファイルだと 404 がコンソールに残り、本物のエラーが埋もれる |

### 発生したエラーと解決策

- **症状**: 床の遠近線が「光のビーム」に見えて、床に見えない
  → **原因**: 消失点から通路の縁へ引く線を α=0.30・幅1.5 で描いていた（強すぎ）
  → **直し方**: α=0.07〜0.13 に落とした。**遠近線は薄く引く**

- **症状**: 床のスクロール線が防壁を突き抜けて画面の端まで伸びる
  → **原因**: 線の半幅を `margin + (W/2-margin)*t²` にしていた。t=1 で W/2＝画面全幅になる
  → **直し方**: `12 + (W/2-margin-12)*t²`。消失点付近で細く、手前で通路の幅ちょうどになる

- **症状**: 地平線を `H*0.30` にしたら、敵の大半が「空の上」を歩いているように見えた
  → **直し方**: `H*0.22` へ上げ、床の面積を増やした

- **症状**: 音のオン/オフが 🔊/🔇 の絵文字で、環境によって形と大きさが変わる
  → **直し方**: インラインSVGで描いた（`mOn` / `mOff` の表示を切り替える）

- **症状**: 検証用の共通ブラウザ（`./va.sh`）が、途中から別のアプリの画面を映していた
  → **原因**: **`va.sh` の常駐ブラウザは1つで、別セッションと取り合いになる**（同じ時間帯に
    別の担当が `neko-escape` を触っていた）
  → **直し方**: このセッションは会話側の MCP ブラウザ（入口A）で検証した。
    **2人が同時に作業する日は入口を分けること**
