### ✅ TCGdex の「相場（pricing）」を取り込んで、円で表示する（2026-08-20 完了）

TCGdex は既に組み込み済み（ワザ・HP・タイプ・効果文）だが、**`pricing` は取っていなかった**。
2026-08-20 に旧 Pokémon TCG API が実質停止していると分かった際、TCGdex が
Cardmarket(EUR) / TCGplayer(USD) の相場を持つことを実測で確認したので取り込む。

**実測した前提（憶測ではない）**

| 項目 | 実測値（2026-08-20） |
|---|---|
| TCGdex の安定性 | 10回中10回成功 |
| dex 31,520枚のうち TCGdex の本物のIDを持つ行 | **9,508枚（30%）** |
| そのうち相場が返る割合 | 無作為25枚中 **22枚（88%）** |
| **相場が付く見込み** | **約 8,367枚（図鑑全体の約27%）** |
| 為替 | `open.er-api.com/v6/latest/EUR` がキー不要・5回中5回成功。EUR→JPY=184.74 |

**日本語カードは Cardmarket(EUR) しか付かない**（TCGplayer の marketPrice は None）。
つまり **これは欧州市場の相場であって、日本国内の相場ではない**。画面にそう明記する。

- [x] `ingest_tcgdex_price.py` … 相場と為替を取り込む（`prices` / `fx` テーブルを追加。既存を壊さない）
- [x] `app.py` のカード詳細に「参考相場」を出す。**EUR と 円換算を併記**し、
      「欧州市場の生カード相場・PSA鑑定品ではない」と画面に書く
- [x] 取り込みは再開可能にする（途中で止めても続きから）

**完了条件**: 相場のあるカードで EUR と円が出る／相場が無いカードでも画面が壊れない／
出所と「国内相場ではない」旨が画面に出る／`./va.sh` か `see.sh` で目視した。

**画像は 100%（31,520/31,520）収録済み。** ただし内訳に注意:
・14枚は**推定**（`trophy_guess`）
