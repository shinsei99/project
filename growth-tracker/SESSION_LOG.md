## 2026-08-30（サブPC）

### 完了したこと
- **新規アプリ GrowLog（`growth-tracker`・ツール分類）を作った。** Vite 8 + React 19 + TypeScript +
  Tailwind CSS v4 + recharts 3。データは localStorage のみ（`growth-app:` 接頭辞）。
- 画面は4つ（ホーム／グラフ／くらべる／カレンダー）＋初期設定＋設定。仕様どおり、
  1日1件・同じ日は上書き、記録の修正と削除、家族の登録と削除、バッジ（初回・+1cmごと・7日/30日連続）
  と獲得演出、開発用のサンプル投入、全データ削除（確認つき）まで実装。
- PWA: `manifest.json`・`sw.js`・アイコン（192/512/maskable/apple-touch）。
  **service worker は本番ビルドでだけ登録**する（開発中はキャッシュで混乱するため）。
- 検証: `va.sh` で Console エラー0件、3幅（390/768/1440）で崩れ0件。
  本番ビルドを配信して manifest と sw.js が 200 で読まれることまで確認。

### 発生したエラーと解決策
- **見た目が幼稚園児向けだと指摘を受けた**（丸ゴシック＋パステル＋絵文字＋ひらがな主体）。
  小学校中学年〜中学生向けに作り替え: 表記を漢字中心（しんちょう→身長）、書体を Hiragino Sans、
  配色を インディゴ／ティール／スレート、角丸を控えめに、タブは絵文字→線アイコン、
  アプリ名も「のびのび」→「GrowLog」に変更。
- **目標身長の線でグラフが潰れた**（目標150cm・現在120cmで変化が読めない）。
  目盛りの中に入るときだけ線を描き、遠いときは「目標まであと◯cm」を文字で出す形にした。
- **recharts の onClick / Tooltip formatter が型エラー**（`CategoricalChartFunc` と合わない）。
  `(state: unknown)` で受けて `activePayload[0].payload` を取り出し、Tooltip は既定表示にした。
- **棒グラフ（くらべる）が1人のとき横いっぱいに伸びた** → 棒に `max-w-16` を付けた。
- `apple-mobile-web-app-capable` の非推奨警告 → `mobile-web-app-capable` を併記。
