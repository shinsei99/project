# 事業計画案ジェネレーター（business-plan-generator）

不動産取得の投資収支「事業計画案」を、物件情報・資金条件の入力から自動作成する社内ツール。
会長の既存「事業計画案」約80本の共通様式を踏襲し、収支・利回り・キャッシュフロー・諸費用内訳を
自動計算して **Excel（.xlsx）** で出力する。金額の単位は原則 **万円**。

- カテゴリ: 不動産（社内LAN共有・launchd常時起動）
- port: **8527**
- 技術: Streamlit + openpyxl（PDF解析は pdfplumber / PyMuPDF）

## できること

1. **入力**
   - フォーム手入力（物件概要／資金計画／収入／支出・借入／諸費用の率）
   - 謄本・マイソク **PDF を AI 読取して自動プリフィル**（所在地・面積・構造・築年）
     - `baikai-generator/services/registry_parser.py` を再利用（`claude` CLI ビジョン）
2. **自動計算**
   - 資金計画：総事業費・借入・自己資金
   - 収入：賃料×12（建設協力金返済の控除に対応）
   - 支出：固定資産税・火災保険・管理費・**金利（平均＝元本×金利×1/2）**・**償却（定額法＝建物×90%÷残存年数, 残存＝法定耐用−築年）**
   - 返済・**利回り3種**（実／経費金利込／単純）
   - **キャッシュフロー**（借入あり／なしの2案・税込）
   - **諸費用内訳**：登録免許税・不動産取得税・抵当権設定・司法書士・予備費
     - **仲介手数料**＝速算式 `(売買価格×3%＋6万)×消費税`（400万超。200〜400万・200万以下の段階式にも対応）
     - **印紙税**＝2024軽減税率の段階表で自動（例：1億超=16万／5000万超=6万）
     - ※仲介料・印紙のロジックは `realestate-calc`（金融マスター電卓）に準拠
3. **出力（Excel）**
   - 「事業計画案」シート：会長の元様式レイアウトを再現
   - 「前提条件」シート：**黄色セル＝入力値**。ここを変えると利回り・CF等が **Excel 上でライブ再計算**（数式リンク）

## 起動

```bash
./run.sh          # 初回は .venv 作成 + 依存インストール、port 8527 で起動
```

## 疎通確認

```bash
.venv/bin/python smoke_test.py   # 計算エンジン + Excel 生成の確認（三神マンション相当のサンプル）
```

## 注意

- 利回り・支出の集計定義は透明性重視の標準的な区分。会長の各案件で細部の入れ方が異なる場合は
  「前提条件」シートで調整可能。
- 個人情報を含む生成 Excel はコミットしない（`.gitignore` 済み）。
