社内向けのアプリを30本ほど、事務所のMacで常時起動させています。
そのうち何本かは**社内で共有するもの**、何本かは**自分専用**です。

自分専用のつもりだったアプリが2本、**社内の誰からでも開ける状態**になっていました。
片方は個人の保有資産の明細を扱う画面です。

起動スクリプトには、こう書いてありました。

```bash
# localhost で起動（社内共有しない）
streamlit run app.py --server.port 8527
```

コメントは正しい意図です。**そして、そのとおりには動いていませんでした。**

## Streamlit の既定は `0.0.0.0`

`--server.address` を省略した場合、Streamlit が待ち受けるのは `0.0.0.0` です。
つまり**全インターフェース**。同じLANの他のPCからブラウザで開けます。

「指定しなければローカルだろう」という思い込みが、そのまま穴になりました。

確認は1行で済みます。

```bash
$ lsof -nP -iTCP:8527 -sTCP:LISTEN
python3  1234  apple  ...  TCP *:8527 (LISTEN)          # ← 全公開
python3  5678  apple  ...  TCP 127.0.0.1:8503 (LISTEN)  # ← ループバックのみ
```

`*:` で始まっていたら公開されています。`127.0.0.1:` なら手元だけです。

## 同じ罠が、別のフレームワークにもあった

これを直した数日後、別のアプリ（Next.js）で同じことが起きました。

```
$ npm run dev
- Local:    http://localhost:3010
- Network:  http://192.168.1.105:3010     # ← 出ている
```

**Next.js の開発サーバーも既定は `0.0.0.0`** です。`--hostname 127.0.0.1` を明示して閉じました。

「開発サーバーだから手元だけ」も、思い込みでした。
Vite、Rails、json-server、その他多数、**既定で外に出るものは珍しくありません**。

## 直し方は「省略しない」

`run.sh` を全部見直して、共有する／しないにかかわらず**必ず書く**ようにしました。

```bash
# 社内共有する（不動産の業務アプリ）
streamlit run app.py --server.port 8503 --server.address 0.0.0.0

# 共有しない（個人用）
streamlit run app.py --server.port 8527 --server.address 127.0.0.1
```

共有するほうも省略しません。**書いてあれば、次に読む人が意図を判断できます。**
省略されていると、「知っていて省いた」のか「知らずに省いた」のかが区別できません。

```
run.sh: バインド先を全アプリで明示（ツール2本がLANに公開されていた不整合を修正）

Streamlitは --server.address を省略すると既定が 0.0.0.0 のため、
「指定なし＝localhost」という前提だった2本が実際には社内LANへ公開されていた
（保有明細・資産額を含むアプリ）。
```

## そして、直しただけでは閉じない

このとき、もう一段ありました。

`run.sh` を直したのに、**常駐しているプロセスの待ち受けが変わらない**。
常駐の定義（plist）が `run.sh` を経由せず、直接コマンドを叩いていたからです。

```
[直したもの]  run.sh  →  手動起動のときだけ使われる
[動いていたもの] plist → 直接 python3 -m streamlit run（アドレス指定なし＝0.0.0.0）
```

**「直した」と「反映された」は別**です。定義を入れ直して、もう一度 `lsof` を見るまでが一組でした。

## 点検の手順

いまは、この3つを1セットにしています。

```bash
# 1. 定義に何が書かれているか
launchctl print gui/$(id -u)/<label> | grep -A2 server.address

# 2. 実際にどこで待ち受けているか
lsof -nP -iTCP:<port> -sTCP:LISTEN

# 3. 外から本当に開けないか（別のPCから）
curl -m 3 http://192.168.x.x:<port>/     # 繋がらないことを確認する
```

3番目まで見る理由は、1と2が「そう書いてある」だけの確認だからです。
**外から叩いて拒否されることを確かめて、はじめて閉じたと言えます。**

## まとめ

- 既定のバインド先は**ループバックとは限らない**。Streamlit も Next.js の dev も `0.0.0.0`
- **省略せずに書く**。共有する側も書く（意図が読める）
- 起動スクリプトを直しても、**常駐が別の起動をしていれば効かない**
- 最後は**外から叩いて確かめる**
