企画から動画まで一式を自動生成するパイプラインを社内で動かしています。
生成AIを業務に組み込むと、**普通のライブラリとは違う壊れ方**をします。4つ挙げます。

## ① モデルが提供終了して 404 になる

ある日から、呼び出しがこう返るようになりました。

```
404 NOT_FOUND: gemini-2.0-flash is no longer available
```

**鍵は有効です。**課金も生きています。指定していたモデルが提供終了していただけです。

紛らわしいのは、**認証エラーと見分けがつきにくい**こと。
「動いていたものが急に 4xx を返す」と、まず鍵を疑ってしまいます。

対処はこうしました。

```python
# 使えるモデルを確認する
for m in client.models.list():
    print(m.name, m.supported_actions)
```

そして、**モデル名はコードに埋め込まず設定で持つ**。
提供終了は今後も起きるので、置き換えが1行で済む状態にしておきます。

## ② SDK そのものが廃止された

モデルだけではありません。**ライブラリごと**終わることがあります。

`google-generativeai` が提供終了になり、`google-genai` へ移行しました。
名前が似ていますが、**呼び出し方が変わります**。

```python
# 旧
import google.generativeai as genai
genai.configure(api_key=key)
model = genai.GenerativeModel("gemini-1.5-pro")
resp = model.generate_content(prompt)

# 新
from google import genai
client = genai.Client(api_key=key)
resp = client.models.generate_content(model="gemini-2.5-flash", contents=prompt)
```

移行のときに効いたのは、**呼び出しを1か所にまとめてあったこと**でした。
各所から直接叩いていたら、置き換えの範囲が読めません。

生成AIのSDKは動きが速いので、**薄いラッパを1枚かませる**価値があります。

## ③ 「思考」にも出力トークンを使うモデルがある

長いプロンプトを投げると、**本文が空**か、**途中で切れる**ことがありました。

原因は、`max_output_tokens` の解釈です。
思考（reasoning）を行うモデルでは、**その思考も出力トークンとして数えられます**。

```python
# 長いプロンプトでこれをやると、思考で使い切って本文が出ない
config = types.GenerateContentConfig(max_output_tokens=4000)
```

さらに悪いのは、**壊れた出力が下流へ流れること**でした。
途中で切れた JSON をパースしようとして失敗し、別経路へフォールバックして、
結果として**遅くなっていました**。

- 上限には**余裕を持たせる**
- **切れた出力は、失敗として扱う**（パースできなかったら、その場で止める）

`finish_reason` が長さ超過を示していたら、そこで気づけます。黙って次へ渡さないこと。

## ④ タイムアウトを指定しないと、待ち続ける

画像生成の試験が、**5分以上返ってきませんでした**。
制限時間を指定していなかったので、ずっと待ちます。

```python
client = genai.Client(
    api_key=key,
    http_options=types.HttpOptions(timeout=120_000),   # ミリ秒
)
```

指定したら、**1枚あたり60秒**で返ってくることが分かりました。
「重い処理だから待つものだ」と思い込んでいると、**ハングと遅いの区別がつきません**。

外部呼び出しには必ず制限時間を付ける。当たり前ですが、
生成AIは実際に時間がかかるので、**つい省いてしまう**ところでした。

## 生成AIを組み込むときの、書き方の方針

4つ踏んだあと、こうしています。

- **モデル名は設定**。コードに埋め込まない
- **呼び出しは1か所**にまとめる（SDKの移行が起きる前提）
- **上限は余裕を持たせ、切れたら失敗にする**
- **必ずタイムアウトを指定する**
- 落ちたら代替へ切り替えてよいが、**切り替えたことは記録に残す**

普通のライブラリなら、バージョンを固定すれば数年は動きます。
生成AIは、**こちらが何も変えなくても、向こうが変わります**。
「動いているから触らない」が通用しない領域だと思って組むのが安全でした。
