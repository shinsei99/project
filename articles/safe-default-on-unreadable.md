業務チャットに常駐しているAIが、未完了タスクの催促を自動で送ります。
**休業日には送らない**という条件が付いています。会社の年間休暇スケジュール（Excel）を取り込んで判定しています。

これが、片方のPCだけ効いていませんでした。**休みの日にも催促が飛んでいた**。
エラーは出ていません。設定画面上は「休業日判定：有効」でした。

## 原因は2段だった

### 1段目：参照先が、別のPCのパスだった

休暇スケジュールの置き場所を、設定に**絶対パス**で持っていました。

```
…/その他のパソコン/マイ Mac mini/Desktop/ルーティーン/年間休暇スケジュール2026.xlsx
```

これは**もう一台のPCから見たときの**クラウド同期フォルダのパスです。
稼働している側には、この場所は存在しません。読み込みは毎回失敗していました。

### 2段目：読めないときに「営業日」を返していた

```python
def is_holiday(date_str: str) -> bool:
    """休業日か。DB の写しを見る（その年が未取り込みなら一度だけ読みに行く）"""
    if query("SELECT 1 FROM holidays WHERE holiday_date=?", (date_str,)):
        return True
    year = date_str[:4]
    if not query("SELECT 1 FROM holidays WHERE holiday_date LIKE ? LIMIT 1", (f"{year}-%",)):
        if refresh().get("count"):
            return bool(query("SELECT 1 FROM holidays WHERE holiday_date=?", (date_str,)))
    return False        # ← 読めなかったときもここに来る
```

一覧が空で、取り込みにも失敗すると、最後の `return False` に落ちます。
**「休業日ではない」＝営業日**として、処理はそのまま先へ進みます。

止まらないようにするための書き方です。実際、判定が使えないだけでAIごと止まったら困ります。
ただ、**この関数の先にあるのは「外へメッセージを送る」動作**でした。

## フォールバックの向きは「機能が動く側」ではない

`False` を返す判断は、「判定できないなら、いつもどおり動かす」という考え方です。
これは**機能を止めない側**に倒しています。

倒す先を、こう考え直しました。

| 判断材料が無いとき | 倒す先 | 結果 |
|---|---|---|
| 内部の処理（集計・表示） | **動かす側** | 多少ズレても、後から直せる |
| **外へ出る動作**（送信・投稿・課金） | **止める側** | 送らなければ、後から送れる |

**取り返しがつくかどうか**で決めます。休みの日に催促を送るのは、取り返しがつきません。
送らなかったぶんは、翌営業日に送れば済みます。

ただし、**止める側に倒したなら、止めたことを言う**必要があります。
黙って止まると、今度は「催促が来ない」という別の障害になります。前に踏んだのと同じ形です。

- 止めた回数と理由を記録する
- 管理画面に「休業日一覧：0件（判定は無効）」と出す

**0件は、機能が効いていないという意味です。** ここを画面に出していれば、その日に気づけました。

## 環境ごとに違うパスを、1つの設定に入れない

もう一つの教訓は、**絶対パスを設定として1つだけ持ったこと**です。

同じアプリを2台のPCで動かしていて、片方はメインで常時起動、もう片方は開発用。
クラウド同期フォルダの実体パスは、2台で違います。設定は共有されていないので、
**片方で正しい値を入れると、もう片方では存在しないパスになる**。

いまは、設定はPCごとに持つものと割り切り、代わりに**結果が見える**ようにしました。

```
休業日: 106件（2026年）  最終取り込み: 2026-08-24 12:31
```

パスが正しいかどうかを目視で確認するのは難しいですが、**件数はひと目で分かります**。

## まとめ

- `try / except` で握るときは、**その先が外に出る動作かどうか**を見る
- 判断材料が無いときは、**取り返しがつく側**へ倒す
- 止める側に倒したら、**止めたことを画面に出す**
- 設定の正しさは、パスではなく**取り込めた件数**で見せる

「エラーを出さずに動き続ける」は、内部処理では美徳ですが、
外へ出る手前では、**そのまま事故になります**。
