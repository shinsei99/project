書類を自動生成するツールで、**出力に前の案件の内容が残る**事故を2通り踏みました。
どちらも、出来上がった書類は**正常に見えます**。だから気づくのが遅れます。

## ① 同梱していたテンプレートが、白紙ではなかった

賃貸の契約書類を、雛形（`templates/*.xlsx`）に値を書き込んで作っていました。

出来上がった書類に、**身に覚えのない会社名**が載っていました。

雛形4本を開いて確認したら、**他社の実案件が記入されたファイル**でした。
どこかから貰ってきたものを、そのまま雛形として置いていたのだと思います。

これが表に出た理由は、**上書きする項目が少なかったから**です。

```python
FORMATS = {
    "賃貸借契約書": {
        "L106": "登記名義人",
        "B12":  "物件所在",
        ...            # 書式ごとに3〜9項目だけ
    },
}
```

書式ごとに上書きするのは**3〜9項目**。残りの欄は雛形のまま出ます。

とくに悪かったのは、**名義人の欄（L106）は上書きするのに、貸主の欄（P65/P67）は対象外**だったこと。
つまり「物件は正しいのに、貸主だけ他人」という書類ができます。

見た目には完成しています。項目が全部埋まっているので、むしろ「よくできた書類」に見えます。

**直し方**: この経路をアプリから外し、**公式の白紙書式から作る**仕組みへ移行しました。

雛形を使う設計そのものが悪いわけではありませんが、**雛形が白紙であることを誰も検証していなかった**。
「上書きされない欄がある」という前提と組み合わさると、そのまま個人情報の漏れになります。

## ② 読み取りが代替へ落ちて、罫線を値にしていた

もう1つは読み取り側です。

登記事項証明書をAIに読ませて構造化していますが、失敗したときのために
**正規表現での読み取り**を用意していました。車庫の謄本でAI側が `JSONDecodeError` になり、
そちらへ落ちました。

そして、こういう値が入りました。

```
種類: │ ② 構 造 │ ③ 床 面 積 ㎡ │ 原因及びその日付…
```

罫線と見出しが、まるごと「種類」の値になっています。原因は2つ。

**行の残りを丸ごと拾っていた。**

```python
# 直す前
m = re.search(r"種\s*類[^\n]+", text)
```

謄本は罫線を文字で描いた表なので、`[^\n]+` は**隣のセルも見出しも全部**拾います。

**`re.search` は最初の一致で終わる。**

表の中では、**見出し行が先に出てきます**。だから見出しをそのまま値にしてしまう。

直したのはこの2点です。

```python
def _cell(s: str) -> str:
    """罫線で区切られた最初のセルだけを取り、見出し語なら捨てる"""
    head = re.split(r"[│┃|]", s, maxsplit=1)[0]
    head = head.strip()
    return "" if head in HEADINGS else head

value = ""
for m in re.finditer(r"種\s*類([^\n]+)", text):   # search → finditer
    value = _cell(m.group(1))
    if value:                                     # 最初の「中身のある値」を採る
        break
```

## 共通しているのは「落ちたことが見えない」

2つとも、**処理としては成功している**のが問題でした。

| | 起きたこと | 見た目 |
|---|---|---|
| ① | 雛形の内容が残る | 全項目が埋まった、きれいな書類 |
| ② | 代替の読み取りに落ちた | 値が入っている（中身は罫線） |

②については、**代替へ切り替わったことを記録に残す**ようにしました。

```
[registry] AI解析に失敗 → 正規表現で読み取り（精度が落ちます）
```

画面にも出します。**「いま精度の低い経路を通った」**と分かれば、出力を疑えます。
黙って切り替わると、利用者はいつもと同じ品質だと思って使います。

## 書類を作るツールでの教訓

- **雛形は、白紙であることを確認してから同梱する**（貰い物をそのまま置かない）
- **上書きしない欄がある**なら、そこに何が残るのかまで見る
- フォールバックは、**落ちたことを表に出す**
- 正規表現で表を読むときは、**最初の一致ではなく最初の中身**を採る

不動産の書類には、当事者の氏名・住所が入ります。
**前の案件の痕跡が残るのは、単なるバグではなく、他人の個人情報を配ること**になります。

うちはこれを、社内で気づけました。外に出る前でよかった、という話です。
