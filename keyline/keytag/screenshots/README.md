# App Store のスクリーンショット

**タップを一切使わずに、シミュレータから撮る。** シミュレータには NFC が無く、
このMacでは **Simulator.app のウインドウが開かない**（`System Events` で
`count of windows` = 0。原因未特定）ので `simtap.py` が使えないため。

代わりに「アプリ本来の**お試し（サンプルの鍵）**を入れて、指定の画面を開いた状態で
起動する」一時ビルドを作り、`xcrun simctl io screenshot` で撮る。
**出る画面もデータも、実際に使ったときと同じもの**（作り物の画面ではない）。

```bash
./shoot.sh read list lend write server     # 5枚まとめて
./shoot.sh server                          # 1枚だけ撮り直し
```

- 撮影用の細工は **`ios/App/App/public/app.js` にだけ**足す。`www/` は触らない
- 撮り終わると `public/app.js` を `www/app.js` で上書きして戻す（細工を残さない）
- 出力は `<このフォルダ>/shots/*.png`（1206×2622）

## App Store へ入れるまで

```bash
# 1) 規定の寸法へ（6.5型 = 1284×2778）。シミュレータの素の解像度は弾かれる
for f in shots/*.png; do sips -z 2778 1284 "$f" --out "$(basename "$f")"; done

# 2) 入れ替える（既存を全部消してから、ファイル名順に入れ直す）
python3 ../push-screenshots.py . --apply
```

## 並び順（2026-08-28 決定・4.3対応）

**1枚目でアプリの性格が決まる。** 台帳アプリにも NFC ツールにも見えない絵を先頭に置く。

| # | ファイル | 内容 | 意図 |
|---|---|---|---|
| 1 | `01-read.png` | かざして鍵が特定された画面（貸出中・利用者・返却予定） | このアプリの中核。**量産の台帳アプリにも NFC ツールにも無い絵** |
| 2 | `02-list.png` | 台帳（返却期限超過が先頭に赤く出ている） | 業務アプリであること |
| 3 | `03-lend.png` | 貸出（貸出先の候補・返却予定の選択） | 実務の流れ |
| 4 | `04-write.png` | タグに書き込む（鍵番号と本数・容量バー） | 鍵に固有の機能 |
| 5 | `05-server.png` | サーバー連携（`✅ ◯◯ と連携中`・仕様へのリンク） | 量産台帳アプリとの決定的な差 |

## つまずき所

- **ヘッダの「NFC 非対応の端末です」**: シミュレータには NFC が無いのでこう出る。
  対応機種では「NFC 利用可」になるので、撮影用の起動処理で**実機の表示に合わせている**
- **`scrollIntoView` を使わない**: `body` ごと動いてヘッダが下がり、画面の上に
  濃紺の帯が出る。スクロールさせる器は `main`（`overflow-y:auto`）なので
  `main.scrollTop` を動かす。下端合わせのときは、`position:fixed` のタブバーの高さ分よける
