## なぜこの文言なのか（先に読む）

App Store を実測したところ、**`hao du` という開発者が同じ型で量産した台帳アプリ**が
多数ある（`鍵台帳-貸出返却管理2026` / **`賃貸キー受渡し台帳2026`** / `工具貸出台帳 在庫返却管理2026` /
`来訪者パス台帳・貸出返却2026` / `レンタル台帳2026` ほか）。とくに
**「賃貸キー受渡し台帳2026」は大家・不動産仲介・アパート管理者向けで、対象も機能もほぼ同じ**。
4.3 の「他の開発者のアプリと似ている」は、この系統を指していると考えるのが自然。

**決定的な違いは、それらが NFC を使わないこと**（説明文に NFC の語が一切無く、
すべて手入力・端末内完結）。したがって文言の方針はこうなる。

| | |
|---|---|
| ✅ **物理のNFCタグと台帳が結びつく**ことを前面に出す | 量産台帳アプリに無い |
| ✅ **タグ自体に情報を書き込む**（圏外・地下でも読める） | 同上 |
| ✅ **公開APIで自分のサーバーに繋ぎ、複数人で同じ台帳を共有できる** | 同上（あちらは全部端末内完結） |
| ❌ 「◯◯台帳」を名前の主役にしない | 量産群と同じ棚に並ぶ |
| ❌ 「NFCタグリーダー／ライター」として名乗らない | 今度は NFC Tools 系の棚に並ぶ |

**中間に立つ**のが正解。「NFCタグを使う、鍵専用の業務アプリ」。

## 説明（4000字以内）

```
鍵にタグを貼るだけ。かざせば「どの鍵か」「いま誰が借りているか」が、その場で分かります。

紙の台帳に書き忘れることがなくなり、鍵を探し回る時間がなくなります。


■ ほかの貸出台帳アプリとの違い

このアプリは、鍵そのものに貼った NFC タグと台帳が結びつきます。

・鍵を手で探して選ぶのではなく、かざした鍵が自動で特定されます
・物件名・鍵番号・保管場所は、タグ自体に書き込まれます。
　アプリを持っていない人でも、iPhone をかざせば内容が読めます
・電波の届かない地下や現場でも、タグの情報はそのまま読めます
・複数人で同じ台帳を共有したい場合は、お使いのサーバーに接続できます（後述）


■ こんな場面で

・建物やテナントの鍵を、業者や入居希望者に貸し出す
・事務所や倉庫の鍵を、社員が持ち出す
・工具や備品を、現場ごとに貸し借りする
・鍵ボックスの中身が増えて、どれが何の鍵か分からなくなってきた


■ できること

【タグに書き込む】
物件名・鍵の名称・鍵番号・保管場所を、NFC タグに直接書き込みます。
情報はタグ自体に入るので、圏外でも、かざせば内容を確認できます。

【かざして確認】
タグにかざすと、その鍵の情報と、いま誰が借りているかが表示されます。

【貸出・返却を記録】
そのまま貸出先を選んで［貸出する］。返すときはかざして［返却する］。
一度貸した相手は候補に残るので、次からはタップだけで選べます。
返却予定を過ぎた鍵は一覧の先頭に赤く表示されるので、返し忘れに気づけます。

【鍵の本数も管理】
「10001 が 1 本、10002 が 1 本」「10003 が 3 本」のように、
番号ごとの本数を登録できます。返却時に「3 本すべて揃っているか確かめて」と表示されるので、
セットの鍵が 1 本足りないまま戻される事故を防げます。

【台帳】
登録した鍵の一覧を、貸出中・返却期限超過が先頭に来る順で表示します。
CSV 形式で書き出すこともできます。


■ 記録はすべて端末の中だけ

会員登録は不要です。入力した内容が外部に送信されることはありません。
広告も、利用状況の解析（トラッキング）もありません。


■ 複数人で共有したい場合（任意）

お使いのサーバーと連携すると、貸出・返却の記録が端末ではなくサーバーに保存され、
他の端末やパソコンからも同じ台帳を見られます。二重貸出はサーバー側で止まるので、
2 人が同時に操作しても記録が壊れません。

接続先はご自身で指定します。特定のサービスへの加入は必要ありません。
接続仕様は公開しており、参照実装（1 ファイル・追加インストール不要）も配布しています。

　仕様と参照実装： https://shinsei99.github.io/project/keytagnfc-support/api.html

※ この設定は任意です。設定しなくても、すべての機能をお使いいただけます。


■ ご利用に必要なもの

・iPhone 7 以降（NFC の読み書きに対応した機種）
・NFC タグ … NTAG213 / NTAG215 / NTAG216 など、NDEF 対応で書き換え可能なもの

※ iPad には NFC リーダーが搭載されていないため、本アプリは iPhone 専用です。
※ NTAG213（144 バイト）は容量が小さいため、名前が長いとタグ上では省略されます。
　 その場合も鍵番号と保管場所は必ず記録されます。長い名前をそのまま入れたい場合は
　 NTAG215 以上をお使いください。


■ タグをお持ちでない方へ

「設定 > お試し」からサンプルの鍵を入れると、タグがなくても
台帳・貸出・返却の動きをお試しいただけます。
```

```
【Guideline 4.3(a) について】

前回 4.3(a)（他の開発者のアプリと似ている）でリジェクトをいただきました。

1. ソースコードとアセットは自社で書いた独自のものです。
   アプリテンプレートの購入・流用は一切ありません。当社が App Store で
   公開している他のアプリとも、コード・素材を共有していません。

2. 「鍵の貸出台帳」を名乗るアプリは複数存在しますが、それらは
   いずれも手入力による記録で、NFC を使用しません。本アプリの中核は
   「物理の鍵に貼った NFC タグと台帳を結びつけること」です。
   ・鍵をかざすと、その鍵が自動的に特定されます
   ・物件名・鍵番号・保管場所は NFC タグ自体に書き込まれ、
     アプリが無い端末でも、通信圏外でも読み取れます

3. 自分のサーバーに接続して、複数人で同じ台帳を共有できます。
   接続仕様は公開しており、参照実装も配布しています。

   仕様と参照実装:
   https://shinsei99.github.io/project/keytagnfc-support/api.html

4. 鍵番号ごとの本数管理（例: 番号 10003 が 3 本）を行い、返却時に
   本数の確認を促します。鍵の運用に固有の機能です。

【動作確認の方法】

本アプリは NFC タグの読み書きを行うため、動作確認には物理的な NFC タグ
（NTAG213/215/216 等）が必要です。

タグをお持ちでない場合は、「設定 > お試し」の［サンプルの鍵を入れる］を
お試しください。台帳・貸出・返却のすべての機能をタグなしでご確認いただけます。

https://shinsei99.github.io/project/keytagnfc-support/

「設定 > サーバー連携」は任意の機能です。設定しなくても、鍵の登録・貸出・
返却・台帳のすべてが端末内で動作します。初期状態では無効です。

記録はすべて端末内に保存され、当社のサーバーへ送信されることはありません。
本アプリは iPhone 専用として提出しています（iPad には NFC リーダーが
搭載されていないため）。
```

## スクリーンショットの並び（2026-08-28 決定）

**1枚目でアプリの性格が決まる。** 台帳と NFC の両方が伝わる順にする。

| # | 内容 | 意図 |
|---|---|---|
| 1 | **かざして鍵が特定された画面**（貸出中・貸出先・返却予定） | このアプリの中核。台帳アプリにも NFC ツールにも無い絵 |
| 2 | 台帳の一覧（貸出中・期限超過が先頭） | 業務アプリであること |
| 3 | 貸出（貸出先の候補・返却予定の選択） | 実務の流れ |
| 4 | タグに書き込む（鍵番号と本数） | 鍵に固有の機能 |
| 5 | サーバー連携（複数人で同じ台帳を共有） | 量産台帳アプリとの決定的な差 |

旧の並び（NFC の読み書きを先頭）は、NFC ユーティリティに見えるので使わない。
